# 仮題『TRACE ONLINE（トレース・オンライン）』

> 「あなたの行動の痕跡（トレース）が、そのままステータスになる」

ソロ・無料・ブラウザで遊べる、**ラノベ／Web小説に出てくる“あのゲーム”**を目指すRPG。
テーマは **「成長」と「リアリティ」**。

- 異世界ステータス系：スキル・熟練度・称号・派生スキル・隠し職業・システムメッセージ
- VRMMO系（シャンフロ/SAO的）：高い自由度、プレイヤースキルが効く戦闘、ユニークシナリオ、「世界初」の発見
- 作中設定：プレイヤーは**「リアルすぎて賛否両論のフルダイブVRMMO」**を遊んでいる。他プレイヤーはNPCとしてシミュレートされ、攻略掲示板が実際に動く
