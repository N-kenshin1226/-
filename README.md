# 仮題『TRACE（トレース）』

> 「あなたの行動の痕跡（トレース）が、そのままステータスになる」

ソロ・無料・ブラウザで遊べる、**ラノベ／Web小説に出てくる“あのゲーム”のシステム**を持つ生活×冒険RPG。
テーマは **「成長」と「リアリティ」**。最優先は **「飽きないこと」**。

- 異世界ステータス系＋シャンフロ/SAO的システム：熟練度、称号、派生スキル、認定職、ユニークシナリオ、システムメッセージ、「世界初」
- 太閤立志伝的な自由：身分×生業の2軸で生き方を選ぶ。ミニゲーム多め（アクション系も含む）
- 一生＝1周：任意の引退 → 伝記 → 転生（継承）で周回する
- 世界観：和風ファンタジー（王道ファンタジーの骨格に、和風の身分制・語彙）※会議で推奨、オーナー確認待ち
