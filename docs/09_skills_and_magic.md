# 09. 技・魔法（なろう系・MMOの多彩さ）

> 目標：**戦闘で使える手が多く、組み合わせを考えるのが楽しい**こと。なろう系の「スキル獲得・進化・ユニーク」の気持ちよさと、MMOの「技の性質・相性・構成（ビルド）」の奥行きを両方持つ。

## 1. 3つの層

| 層 | 中身 | 例 |
|---|---|---|
| **技能** | 熟練度 0〜100（既存。`02_growth_system.md`） | 剣術 34.2、火魔法 12.0 |
| **技・魔法** | 技能の熟練度で覚える、戦闘や生活で使う個々の手。**Lv1〜10**で、使うほど育つ | 剣術の《兜割り》Lv3、火魔法の《火球》Lv5 |
| **上位・派生・ユニーク** | 進化・合成・特別な条件で手に入る | 《火球》→《炎槍》、剣術＋火魔法→《焔剣》、ユニーク《???》 |

- 獲得はシステムメッセージで知らせる：`――条件を満たしました。技《兜割り》を習得しました。`
- 技・魔法の Lv も使用回数と相手の格で上がる（技能と同じ「格上ほど伸びる」考え方。起床ログで定着）

## 2. 戦闘の資源
- **体力**：なくなると倒れる
- **気力**：武技を使うと減る。時間（CT）と休息で戻る
- **魔力**：魔法を使うと減る。時間・休息・瞑想・道具で戻る
- 既存の CT（チャージタイム）制に乗せる。技ごとに CT・消費・予兆への対応力が違う

## 3. 武技（武器ごとに 6〜10 個）

| 武器 | 特徴 | 技の例 |
|---|---|---|
| 剣 | 万能・受け流し | 斬り払い、二連撃、兜割り、突き、受け流し返し、燕返し（上位）、居合（派生） |
| 短剣 | 速い・急所・状態異常 | 急所突き、投げ短剣、影討ち（隠密中）、毒塗り、連刃 |
| 槍 | 間合い・複数の敵 | 薙ぎ払い、突進、間合い制圧、石突き（体勢崩し） |
| 斧 | 重い・防御破壊 | 叩き割り（防具破壊）、旋回、大振り |
| 弓 | 遠距離・部位狙い | 狙い撃ち、二連矢、弱点射ち、曲射、縫い止め |
| 盾 | 守り・崩し | 盾構え、盾打ち（気絶）、挑発、反射 |
| 格闘 | 素手・連打・投げ | 掌底、投げ、連打、関節極め |
| 投擲 | 補助 | 石礫、煙玉、油壺（火魔法と組む） |

**技の性質**（全部データで持つ）
- 攻撃の種類：斬・突・打・魔（敵ごとに得意不得意）
- 部位狙い（頭・胴・腕・脚。既存の部位ダメージ）
- 状態：出血・気絶・体勢崩し・鈍足・毒・燃焼・凍結・感電
- **予兆への対応**：割り込み（大技を止める）、受け流し（返す）、回避、受け止め。どの技がどの予兆に強いかが違う
- 消費・CT・射程（近・中・遠）

## 4. 魔法

### 系統と適性
- **属性魔法**：火・水（氷）・風（雷）・土・光・闇
- **無属性**：身体強化、障壁、魔力弾
- **生活魔法**：着火、灯り、浄化、乾燥、冷却（なろう系の定番。**戦闘以外で役立つ**：料理の火加減、鍛冶の温度、野営、採集物の保存）
- **治癒**：光と祈祷に近い。医術とも組む
- 基礎の技能として**魔力操作**がある。すべての魔法の安定・消費・詠唱の短さに効く
- 適性（属性ごとの素質）は出自とシードで決まる。**主人公は平凡なので、適性も並**。特別な適性は誰にも与えない

### 覚え方（謎解き不要。複数の道）
- 書物（魔導書）を読む、師匠に習う、見取り稽古（敵やNPCの魔法を観察して耐える）、生活魔法を使い続けて派生させる

### 詠唱
- 魔法は**詠唱**の時間がかかり、その間に攻撃されると中断されうる（敵の予兆と同じ仕組みを、こちら側に持つ）
- 熟練で短縮。極めると**無詠唱**（なろう系の定番。パッシブとして獲得）

### 生活と職人への広がり
- 鍛冶＋火魔法：温度管理が楽になる。極めると**付与（エンチャント）**で魔剣を打てる
- 料理＋火・水：火加減・下ごしらえ
- 農耕＋水・土：収穫
- 調合＋各属性：魔法薬

## 5. 相性とコンボ（MMOの奥行き）
- **属性の相性**：濡れ＋雷＝感電、油＋火＝延焼、凍結＋打撃＝砕く、風＋火＝火勢拡大
- **崩しからの大技**：体勢崩し → 次の重い一撃が会心
- **部位破壊**：腕を壊すと大技が出せない、脚を壊すと逃げられない
- **敵の耐性**：斬に強い骨の魔物、火に強い火トカゲ…。同じ構成では全部の敵に勝てない

## 6. 構成（ビルド）
- 戦闘に持ち込める技・魔法は**8枠**（武技と魔法を自由に混ぜる）。パッシブは別に**4枠**
- 武器は2つまで持ち替えられる（持ち替えに CT）
- 構成は街でいつでも組み替えられる。組み合わせを考えること自体が遊び

## 7. 進化・合成・ユニーク（なろう系）
- **進化**：技・魔法が Lv10 に達すると上位に進化する。**どの方向に進化するかは、主人公の使い方の記録（ログ）で決まる**（§7.1）
### 7.1 使い方が進化の向きを決める
TRACE（痕跡）の考え方をそのまま技に当てはめる。**プレイヤーが選ぶのではなく、どう使ってきたかで技が育つ。**

- 技・魔法を使うたびに、その時の**状況**を記録する（例）
  - 相手：一体／群れ、格上／格下、種族（獣・人・不死・魔物）、属性
  - 狙い：部位（頭・脚…）、急所、体勢崩しの後か
  - 状況：隠密中、受け流しの直後、詠唱を中断されかけた、HP が少ない（死線）、仲間と一緒、夜・雨
  - 組み合わせ：直前・直後に使った技、属性の重ね（濡れ＋雷…）
  - 戦闘以外：鍛冶・料理・採集・野営で使った
- 進化の分岐ごとに、**どんな使い方に向いているか**（状況の重み）をデータで持つ。Lv10 に達したとき、**記録と最も合う分岐**へ進化する
  - 《火球》を群れに撃ち続けた → 《爆炎》（範囲）
  - 格上の一体に撃ち込み続けた → 《炎槍》（貫通）
  - 隠密中や夜に使い続けた → 《鬼火》（静かに燃やす）
  - 鍛冶場の炉で使い続けた → 《鍛火》（鍛冶の温度を極める。戦闘より職人寄り）
- 進化のメッセージで、理由を語る：`――あなたは《火球》を、群れへ放ち続けた。《火球》は《爆炎》へと進化しました。`
- **今どちらに傾いているか**は、ステータスの「技」タブに名前を伏せて示す（例：《火球》の傾き「群れ ▮▮▮▮▯ ／ 一点 ▮▮▯▯▯ ／ 静けさ ▮▯▯▯▯」）。行動を変えれば、向きも変えられる
- 進化した先の名前は、進化するまで `？？？`
- 1つの分岐にしか合わない使い方をしていなくても、必ずどれかに進化する（最も近い分岐）。どの分岐にも当てはまらない極端な使い方は、まれに**隠し分岐**につながる（hidden）
- 技能の熟練度（剣術など）にも同じ考えを広げる：剣術を受け流し中心に使ってきた人と、先手の連撃中心に使ってきた人では、覚える技の順番と種類が変わる

- **合成**：2つの技能・技の組み合わせで、新しい技が生まれる（剣術＋火魔法→《焔剣》、弓＋風魔法→《風切り矢》、隠密＋闇魔法→《影渡り》）。条件は非公開で、ヒントは噂・書物・見聞録
- **ユニークスキル**：その世界で**一人しか持てない**技。とても厳しい条件（偉業・極端な積み重ね）で得る。**ライバルが先に取ることもある**。取った人は年代記と新聞に載る（世界初の仕組み）。生まれつきではなく、行動で得る（平凡な主人公の方針どおり）

## 8. 見せ方
- ステータスに「技」タブ：技能ごとに、覚えた技と Lv、進化の先（未到達は `？？？`）
- 構成画面：8＋4枠のスロット
- 戦闘画面：技のスロットを並べ、消費・CT・予兆への相性をアイコンで示す

## 9. 面白さの検証（sim）
- **構成の多様性**：上位の勝率を出す構成が1つに偏らない（複数の構成がそれぞれ得意な敵を持つ）
- **すべての技が使われる**：sim のボットの使用履歴で、使われない技・魔法がない
- **連打で勝てない**：格上の敵には、相性・予兆への対応・構成の工夫が必要

## 10. 量の目安
- 武技 約60、魔法 約40（生活魔法を含む）、パッシブ 約20、上位・合成 約30、ユニーク 約10（隠し）
- 技・魔法のデータは JSON。合成とユニークの条件は `packages/content/hidden/` に置く（オーナーは読まない）
