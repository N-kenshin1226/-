# 08. 世界の危機と真エンド

> この文書は**仕組み**だけを書く。危機の具体的な中身（原因・筋書き・結末の語り）は `packages/content/hidden/crises/` に置き、オーナーは読まない（`07_story.md` §5 のネタバレ防止）。

## 1. 方針（オーナーの決定）

1. **世界を主人公に背負わせない。** 世界の危機は、世界の人々（王国・ギルド・ライバル・名もない人々）が動かし、決着させる。主人公向けのクエストにしない
2. **でも、めっちゃ頑張れば英雄にもなれる。** 関わるほど役割が大きくなり、頂点級に積み上げれば決着の中心に立てる。保証はなく、勝ち取るもの
3. **危機はシードごとに違い、筋書きもシードごとに違う**
4. **謎を解く必要はない。** 何が起きているかは、新聞・噂・景色の変化で自然に分かる
5. **主人公は平凡。** 転生すること以外は普通の人。選ばれし者・血筋・特別な運はない
6. **世界が滅ぶのは、たまにだけ**
7. **頂点ルートは人生の目標。** いくつ同時に追ってもよい
8. **生き方をルートや型に縛らない。** 生き方は「プレイヤーが実際にしたこと」の積み重ねであって、選んだ型ではない。どんな組み合わせの生き方でも、危機との接点があり、英雄まで届きうる

## 2. 全体の流れ

```
新しい世界（シード）
 └ 危機を1つ抽選（型 × 変数）＝ この世界の歴史の筋書き
     兆し → 拡大 → 深刻 → 決着の場面（1〜3回） → 終幕
       ├ 世界の勢力が勝手に「備え」を積む（力・技・縁・財・知）
       ├ 危機は主人公の日常に「接点」として混ざる（受けるかは自由）
       └ 関わるほど主人公の「関与」が上がり、役割が大きくなる
 決着の場面の結果 → 解決（多くの世界）／滅び（たまに）
 → 終幕の語り（真エンド）：主人公の痕跡が、関与の大きさに応じて織り込まれる
 その後：その世界で生き続けてよい／子・弟子に継ぐ／引退して転生（次の新しい世界へ）
```

## 3. 危機（世界の歴史の筋書き）

- **危機の型**（例：霧、疫病、竜の目覚め、王家の内乱、古代遺跡の暴走、異界の門）は人の手で作り込む（Opus 5.5 が書き、隠しフォルダに置く）。シードで変わるのは型の中の**変数**（原因の所在、関わる勢力と人物、場所、決着の場面の種類と時期）。MVPは **3種類**
- 段階は季節の変わり目に進む。段階ごとの**影響**をデータで定義する（エリアの閉鎖・開放、物価、NPCの離散・死亡、敵の強さ、危機の中でだけ出る依頼・素材・場所）
- **画面に危機の段階を常に出さない。** 新聞・噂・景色・物価・人の不在で知る。ステータス画面の年代記タブにだけ、これまでの出来事を記録する
- 危機は脅威であると同時に機会でもある（危機の中でしか手に入らない素材・仕事・場所）

## 4. 世界の備えと決着

- 世界の勢力は、季節ごとに**備え**を5つの分野（力・技・縁・財・知）に積んでいく（勢力ごとの得意分野と速さはシードで決まる）
- 危機には**決着の場面**が1〜3回ある（例：討伐の遠征、和平の会議、儀式、最後の防衛戦）。時期は筋書きで決まり、場面ごとに必要な分野が違う
- 決着の場面の成否は、その時点の**備え**（世界の分＋主人公が寄与した分）で決まる。乱数は控えめにする
- 主人公が何もしなくても、多くの世界は決着する。重い危機（約15%）で備えが足りないと**滅び**になる

## 5. 接点：危機は日常に混ざる

危機は、主人公の生き方の延長として現れる。**受けても受けなくてもよく、断っても不利益はない。**

- **接点は「生き方の型」からではなく、プレイヤーが実際にしてきたこと（直近の行動の履歴・スキル・人間関係・持ち物・いる場所）から選ぶ。** 鍛冶と剣を両方やっていれば、両方の接点が来る
- 主流でない生き方（釣り、演奏、料理、鑑定、旅…）にも接点を用意する。どの行動にも、何らかの分野への寄与の道がある
- 下の表は例であって分類ではない

| 行動の例 | 接点の例 | 寄与する分野 |
|---|---|---|
| 鍛冶・職人 | 討伐隊からの大口注文、失われた製法の再現依頼 | 技・力 |
| 商い | 物資不足の町への輸送、価格の高騰 | 財 |
| 戦い | 町の防衛、街道の魔物退治、遠征への誘い | 力 |
| 交渉・人脈 | 避難民の受け入れ、勢力同士の仲裁 | 縁 |
| 学び | 古い記録の調査依頼、書物の写本 | 知 |
| 釣り・料理 | 包囲された町への食糧、避難民の炊き出し | 財・縁 |
| 演奏 | 士気を上げる演奏、各地を回って噂を集める | 縁・知 |

- 接点は既存の遊び（注文・依頼・戦闘・ミニゲームの勝負所・交渉・書物）に乗せる。危機のための新しい遊びは作らない
- 接点で積んだ寄与は、その分野の**備え**に加わる（主人公一人の寄与は、普通に暮らしている範囲では世界全体の一部にとどまる）

## 6. 関与と、英雄への道

主人公の**関与**は、危機に関わる行動の積み重ねと、名声・立場・関連スキルで決まる。関与が上がると、世界から**声がかかる役割**が大きくなる。

| 段階 | 状態 | 世界からの扱い |
|---|---|---|
| 1 見届けた | ほとんど関わっていない | 新聞と噂で知る |
| 2 支えた | 接点をいくつか受けた | 注文や依頼が増える。結末で名もなき形で語られる |
| 3 担った | 決着の場面の準備に深く関わった | 決着の場面への参加を打診される（勝負所・戦闘として遊べる） |
| 4 率いた（英雄） | 頂点級の力か、大勢力を動かせる人脈がある | 決着の場面を**自分で起こせる**（時期を早める、やり方を選ぶ）。成否は主に自分の備えで決まる。名前が歴史に残る |

- 段階4は**本気で一生を懸けて届くかどうか**の高さにする。片手間では届かない
- 世界は主人公を待たない。決着の場面が来たときに力が足りなければ、ほかの誰かが挑む
- 関与は**分野をまたいで合算する**。一つの道を極めた人も、いろいろな道で少しずつ関わった人も、同じように上の段階に届く（混ざった生き方を不利にしない）
- 頂点ルートは**近道であって条件ではない**。頂点に至っていると上の段階に届きやすい（剣聖なら遠征の要に、商王なら勢力を動かす財に、職人なら決戦の装備に）が、頂点がなくても段階4に届く道を必ず残す
- 決着の場面での役割は、主人公の実際の得意（スキルと実績）から決まる。剣が立てば前線、交渉が得意なら会議、職人なら装備、何でも少しずつなら全体のまとめ役

## 7. 終幕（真エンド）

- **その世界の物語の終幕を、生きて見届けること**が真エンド。決着の結果（解決／滅び）、危機の型と変数、主人公の関与の段階で語りが変わる
- 語りには、主人公の痕跡が関与の大きさに応じて織り込まれる
  - 段階2：「討伐隊が携えた剣のうち、最も折れなかった一振りは、職人街の名もなき若者が打ったものだったという」
  - 段階4：英雄として名が刻まれる
- 演出：ランクSの通知 → 結末画面（紙の層の語り＋その世界の年代記の一頁）。その後もその世界で遊べる
- 人生のうちに決着しなかった場合：子・弟子の代で見届けるか、転生のときに「あなたが去った後、この世界は…」という後日談が年代記に残る

## 8. 面白さの検証（`pnpm sim:crisis`）

| 指標 | 合格の条件 |
|---|---|
| 世界が自分で動く | 何もしないボットでも、通常の危機の大半（目安80%以上）が決着する |
| 滅びはたまに | 何もしないボットでの滅びの割合が、設定値（約15%）の範囲内 |
| どの生き方にも接点 | 鍛冶・商い・戦い・人脈・学びに加え、混ざった生き方（例：鍛冶＋剣）と主流でない生き方（例：釣り＋演奏）のボットそれぞれに、ゲーム内1年あたり一定数以上の接点が出る |
| 英雄は勝ち取るもの | 危機に集中するボットは、一生のうちに段階4に届く世界がある。片手間のボットはほぼ届かない |
| 縛られない | 頂点ルートに一つも至らないボット、混ざった生き方のボットでも、段階4に届く世界がある |
| 関わると変わる | 段階3以上のボットの世界では、決着の成功率が何もしない場合より有意に高い |
| 見える | 開始から1時間以内に、危機の兆しが新聞か噂に出る |
