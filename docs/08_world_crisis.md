# 08. 世界の危機と真エンド

> この文書は**仕組み**だけを書く。危機の具体的な中身（原因・結末の語り・鍵の詳細）は `packages/content/hidden/crises/` に置き、オーナーは読まない（`07_story.md` §5 のネタバレ防止）。

## 1. 方針（オーナーの決定）

1. **世界の危機はシードごとに違い、答えもシードごとに違う。** 前の世界の攻略をなぞっても解けない
2. **謎を解く必要はない。** 何が必要かは、世界の人々が調べて公にしていく。物語の断片を集めると、近道や別の道が見つかる（あると得をするが、なくても解ける）
3. **主人公は平凡。** 転生すること以外は普通の人。選ばれし者ではない。運も血筋も特別ではない。世界はほかの人々も救おうとしている
4. **頂点ルートは「人生の大きな目標」**で、いくつ同時に追ってもよい。物語の章立てはルートには持たせない
5. **世界が滅ぶ結末は、たまにだけ起きる**

## 2. 全体の流れ

```
新しい世界（シード）
 └ 危機を1つ抽選（型 × 変数）
     兆し → 拡大 → 深刻 → 臨界   … 季節ごとに進む（数十年規模）
       │      │      │
       │      └ 必要な「鍵」が世間に公示されていく（新聞・掲示・噂）
       └ 世界が目に見えて変わる（町が閉ざされる、物価、NPCの離散・死、敵の強化）

 鍵がすべて揃う（誰が揃えてもよい）→ 危機の解決 → 真エンド（この世界の結末）
 臨界まで放置（重い危機のときだけ）→ 滅びの結末
 どちらの後も：その世界で生き続けてよい／子・弟子に継ぐ／引退して転生（次の新しい世界へ）
```

## 3. 危機

### 型と変数
- **危機の型**（例：霧、疫病、竜の目覚め、王家の内乱、古代遺跡の暴走、異界の門）は人の手で作り込む（Opus 5.5 が書き、隠しフォルダに置く）
- シードで変わるのは型の中の**変数**：原因の所在、鍵を握るNPC、場所、必要な鍵の組み合わせ、各鍵の道筋の数値
- MVPでは型を **3種類**。同じ型でも変数の組み合わせで別の世界になる

### 進行
- 段階：`兆し → 拡大 → 深刻 → 臨界`。季節の変わり目に、進行値が貯まると次の段階へ進む
- 偉業（鍵の一部の達成、関連する討伐や納品）で進行を**押し戻せる**
- 段階ごとに、世界への**影響**をデータで定義する（例：エリアの閉鎖・開放、物価の倍率、NPCの離散・死亡、敵の強さ、新しい依頼や素材の出現）
- 危機は脅威であると同時に機会でもある：危機の中でしか手に入らない素材・依頼・場所を必ず用意する

### 重さ（滅びは「たまに」）
| 重さ | 出現率の目安 | 臨界に達すると |
|---|---|---|
| 通常 | 約85% | 世界は「停滞」する（暮らしは苦しいが続く）。解決はいつでも可能 |
| 重い | 約15% | **滅びの結末**。年代記に「救われなかった世界」として残る |

- 重い危機は、序盤から兆しで「いつもより重い」と分かるようにする（不意打ちで滅ぼさない）
- 臨界までの期間は長くとる（標準的な遊び方で、子・弟子の代まで含めて十分に間に合う長さ）

## 4. 答え：鍵

### 鍵の分野
| 分野 | 例 |
|---|---|
| **力** | 番人・元凶の眷属を倒す、危険な場所を突破する |
| **技** | 失われた製法の品を作る、壊れたものを直す |
| **縁** | 対立する勢力を和解させる、人を集める、協力を取りつける |
| **財** | 必要な物資・資金を調達する、道を通す |
| **知** | 記録を見つける、正しい場所・時期を突き止める |

- 1つの危機に必要な鍵は **3〜4個、すべて異なる分野**（組み合わせはシードで変わる）
- 鍵は**世間に公示される**：段階が進むごとに、学者・ギルド・王国がNPCとして調べ、新聞や掲示板で「〇〇を求む」と出す。プレイヤーが謎を解かなくても、必要なものは分かる
- 物語の断片（見聞録）を集めていると、**公示より早く**鍵が分かったり、**もっと安い・別の道**が見つかったりする（得をするだけで、必須ではない）

### 鍵の取り方：自分でやるか、人を動かすか
各鍵には、**少なくとも3つの道**を用意する。

| 道 | 内容 |
|---|---|
| 自分の腕 | 戦闘、ミニゲームの勝負所、交渉。スキルが高いほど楽 |
| 依頼 | 名工に作ってもらう、腕利きに頼む。お金・素材・人間関係がかかる |
| 協力 | ライバルや勢力と組む。縁（交渉・評判）が要る |

- 平凡な主人公は、一人で全部をこなせなくてよい。**人を動かすことも攻略**
- 頂点ルートは、ここで「生き方の違い」として効く（剣聖なら力の鍵を自分で取れる、商王なら人を雇える、職人なら技の鍵を作れる）。必須ではない

### ほかの人々も動いている
- ライバルやギルドは、それぞれ勝手に鍵を狙う。先に取られることも、失敗して亡くなることもある
- **鍵は誰が揃えてもよい。** 主人公が関わらなくても、世界が救われることはある
- 真エンドの語りは、主人公の関わり方で変わる（中心になった／一部を担った／見届けた）。どれも「その人生の物語」として年代記に残る

## 5. 真エンド

- **その世界の危機が解決したときの結末**。危機の型と変数、鍵を誰がどう揃えたかで語りが変わる
- 結末には、主人公が関わった人々（依頼した職人、和解させた勢力、助けた町）が登場する
- 演出：ランクSの通知 → 専用の結末画面（紙の層の語り＋その世界の年代記の一頁）
- 解決後も世界は続く。危機の影響は段階的に解けていく（閉ざされた町が開く、去った人が戻る）
- 滅びの結末も同じ形式で、別の語り

## 6. 頂点ルートとの関係

- 頂点ルート（剣聖・伝説の職人・大賢者・商王・領主・英雄）は**人生の目標**。複数を同時に追える。章立ての物語は持たない
- 「3ルート達成で真エンド解放」は**廃止**。真エンドは世界の危機の解決で得る
- 頂点に至ると、危機への関わり方が広がる（例：剣聖は力の鍵の「自分の腕」の道が楽になる、商王は「依頼」の費用が下がる）

## 7. 世代と転生

- 同じ世界の続きは**子・弟子への継承**で遊ぶ（実装済みの継承延長）。危機の進行はそのまま続く
- **引退して転生すると、新しいシードの新しい世界**へ。新しい危機に出会う
- 前世から持ち越せるのは、継承3項目（素質の補正・称号・遺物）と、プレイヤー自身の経験だけ

## 8. 面白さの検証（バランスCIゲートに追加）

`pnpm sim:crisis`（`sim:retention` と同じ仕組みで）次を自動で確かめる。

| 指標 | 合格の条件 |
|---|---|
| 解ける | 戦闘型・職人型・商人型・人脈型のボット**それぞれ**が、すべてのテスト用シードで危機を解決できる |
| 道の数 | すべての鍵に3つ以上の道があり、どれも到達できる |
| 見える | 開始から1時間以内に危機の兆しが、3時間以内に最初の鍵の公示が出る |
| 滅びの頻度 | 重い危機の出現率が設定値（約15%）の範囲内 |
| 間に合う | 標準のボットが、重い危機でも臨界前に解決できる |
| 世界が変わる | 各段階で、目に見える影響が最低2つ起きる |

## 9. データの置き場所

```
packages/content/
├─ crises/schema.ts          # 危機の型・段階・影響・鍵・道のzodスキーマ（公開）
├─ crises/sample.json        # テスト用の公開サンプル（中身は簡単なものでよい）
└─ hidden/crises/*.json      # 本番の危機の型（Opus 5.5 が書く。オーナーは読まない）
```
