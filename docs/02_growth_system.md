# 02. 成長システム（本作の心臓部）

> 実装は `packages/core/growth/` に純関数として置く。
> 数値はすべて `packages/content/balance.json` で調整できるようにし、コードに直書きしない。

## 1. 用語

| 用語 | 定義 |
|---|---|
| **スキル** | 剣術・弓術・隠密・採掘・鍛冶・観察など。値は `0.0〜100.0`（小数1桁、UO式） |
| **基礎能力** | 筋力・持久・敏捷・器用・知覚・精神の6種。スキル使用の「負荷」から伸びる |
| **未定着経験 (pending)** | 行動で得た伸びしろ。睡眠で数値に変わる |
| **素質 (potential)** | スキルごとの学習効率。%で表示（Elona式）。上達で下がり、休養・師匠・書物で回復する |
| **疲労 (fatigue)** | 0〜100。行動で溜まり、学習効率と戦闘性能を下げる |
| **錆 (rust)** | 使わないスキルの表示値が下がる。最高到達値は記憶されている |
| **ランク** | 値に対応する呼称。0 未経験 / 10 見習い / 25 初心者 / 40 一人前 / 60 熟練 / 80 達人 / 95 極み / 100 ??? |

## 2. 経験獲得式

行動1回ごとに、関係するスキルへ次の未定着経験を加算する。

```
gain = B × C(Δ) × N × P × F × M
```

| 項 | 名前 | 内容 | 参考元 |
|---|---|---|---|
| `B` | 基礎量 | 行動の種類ごとの値（攻撃命中 1.0、回避成功 1.2 など） | — |
| `C(Δ)` | 挑戦係数 | `Δ = 行動の難度 − 現在のスキル値`。下の曲線を参照 | Kenshi、相手との差による補正 |
| `N` | 新規性 | 同じ相手・同じ行動を短時間に繰り返すと減衰。`N = 1 / (1 + k × 直近の反復回数)` | Oblivionのジャンプ稼ぎへの対策 |
| `P` | 素質 | `potential / 100` | Elona |
| `F` | 疲労係数 | `F = 1 − (fatigue / 100)^2 × 0.8`。疲労が100でも0.2は残る | — |
| `M` | 修正 | 職業・称号・師匠・書物の倍率の積（上限は ×3） | Project Zomboidの技能本 |

### 挑戦係数 C(Δ)（「格上と戦え」をリアルにする曲線）

```
C(Δ)
1.6 |            ___
1.2 |          /     \
1.0 |         /        \___
0.5 |       /               \______
0.05|______/                        \____ 0.15（格上すぎ：失敗から学ぶ分だけ）
    +------+-----+-----+-----+-----+-----→ Δ
         -20    0    +10   +25   +40
```

- `Δ < −20`（格下すぎ）：**0.05**。雑魚狩りではほぼ伸びない
- `Δ ≈ +10`（少し格上）：最大 **1.6**
- `Δ > +40`（無謀）：**0.15**。ただし後述の「死線ボーナス」がある
- 失敗した行動も経験になる（成功時の0.6倍）。**失敗は学びになる**
- **死線ボーナス**：HPが20%未満の状態で行動して生き延びると、その戦闘中に得た経験が戦闘後に ×1.5。あわせて《胆力》に加算

### 高値帯の逓減（UO式）

スキル値が高いほど1回の伸びが小さくなる。

```
実効gain = gain × (1 − skill/110)^1.5
```

## 3. 定着：経験は「寝て起きると来る」

- 未定着経験は**睡眠時にまとめて数値へ変換**する。睡眠前の時点では、ステータス画面に「(+1.7)」のように薄く表示する
- 1晩の定着上限は `基礎上限 × 睡眠の質`
  - 睡眠の質：宿のランク・野宿・怪我・疲労度で 0.5〜1.2
- 上限を超えた分の50%は翌日に持ち越し、残りは失われる
  → **1日に詰め込みすぎても無駄になる**。自然な休息リズムが最適解になる
- 定着したら朝のシステムログで発表する。ここが本作の最大の快感ポイント

```
━━━━━━━━━ 起床 ━━━━━━━━━
睡眠の質：良好（宿屋《麦穂亭》）
《剣術》  23.4 → 25.1  ▲1.7
《回避》  11.0 → 12.3  ▲1.3
《胆力》   4.2 →  6.0  ▲1.8  ※死線ボーナス
筋力 +0.2 ／ 持久 +0.3
――条件を満たしました。スキル《見切り》を獲得しました。
━━━━━━━━━━━━━━━━━━━━━━
```

## 4. 基礎能力（身体はつくられる：Kenshi的な負荷成長）

- 基礎能力はスキル使用時の「負荷」から伸びる
  - 重い武器を振る → 筋力。長距離を走る・重い荷を運ぶ → 持久・筋力。精密な製作 → 器用。被弾 → 持久・精神（Kenshiの靭性をヒントに）
- 定着は睡眠時（超回復）。**過負荷が続くと「オーバーワーク」状態**になり、翌日の定着量が減り、怪我のリスクが上がる
- HP・スタミナ・積載量・行動速度は基礎能力から計算する派生値

## 5. 素質（potential）

- 初期値：種族・出自で決まり、80〜130%
- スキル値が1上がるたびに、現在の素質の約1%が減る（Elonaは約1/10。本作は緩め）
- 回復手段：十分な休養日（何もしない日）、師匠の指導（お金と時間を払う）、書物（一時的な倍率）
- 素質は「この分野は向いてない／伸び悩み」というリアリティの源になる

## 6. 錆（緩い衰え：Dwarf Fortress式を罰ではない形に緩和）

- 最後に使ってから **14日（ゲーム内）** 経つと、表示値が1日0.1ずつ下がる
- 下限は**最高到達値の70%**。それより下には落ちない
- 最高到達値までの再習得は **×3速**（「身体が覚えている」）
- **脳の容量**：合計スキル値が閾値を超えると、使っていないスキルの錆が早まる（UOの合計700キャップの代わりのソフトキャップ）
  → 何でも極めることはできないが、何も永久には失わない

## 7. 学び方の種類（同じ伸びに複数の道を用意する）

| 方法 | 効果 | 例 |
|---|---|---|
| 実践 | 基本 | 戦闘、採掘、製作 |
| 訓練 | 安全だが、挑戦係数の上限が低い（`C ≤ 0.6`） | 木人打ち、射的場 |
| 師匠 | 素質回復＋一定期間の倍率。お金と時間がかかる | 剣術道場、魔術師の塔 |
| 書物 | 一定のスキル帯でだけ倍率がかかる（PZ式）。読むのに時間がかかる | 『初級剣術指南』は剣術10〜30で×2 |
| **見取り稽古** | 敵やNPCが使う技を《観察》しながら耐えると、その技の「理解度」が溜まる。100%で習得条件を満たす | ラノベ的な「見て覚えた」 |

## 8. 派生スキル・職業・称号

### 派生スキル
- 条件は「複数スキル値＋行動パターン」。例：《隠密》20以上 かつ 《投擲》20以上 かつ「隠密中の投擲命中」50回 → 《暗器術》
- 条件は非公開。書物の断片・NPCの噂・掲示板の考察スレでヒントを出す
- 獲得時はシステムメッセージで通知し、該当する「世界初」なら台帳とワールドアナウンスにも出す

### 職業（ロール認定）
- 職業は「選ぶ」ものではなく**「認定される」**もの。条件を満たすとギルドやNPCから打診が来る
- 効果は生の数値ではなく、**成長の倍率と専用の行動**（なろう的な強さを数値インフレにしない）
- 隠し職業：例《墓守》＝夜の墓地で一定期間アンデッドを狩らずに鎮める、など行動の方向性で決まる

### 称号
- 行動ログのカウンタ・フラグをデータ定義の条件式で判定する（`03_world_systems.md` の称号DSLを参照）
- 効果は小さく、フレーバー重視。「数が多いこと」自体が楽しい
- 例：《百狼斬り》《死に戻り常連》《雨の日の釣り人》《一番乗り》

## 9. ステータス画面の情報設計

- 未獲得のスキル・称号は `???` 表示にする（存在だけ匂わせる）
- 各スキルに「最近の伸び」「錆まであと何日か」「素質」をツールチップで出す
- 「伸び悩み」の理由を表示する（例：*「相手が弱すぎて学びが少ない」*）＝**ブラックボックスにしない**
  → リアリティと理不尽さを分ける最大のポイント

## 10. 調整の検証（Devinに必須で課す）

- `pnpm sim:growth` を用意する。ヘッドレスのボットが方針（雑魚狩り専門／格上挑戦／訓練のみ／バランス型）ごとに30日分遊び、各スキルの推移をCSVで出力する
- 受け入れ基準の例：
  - 「格上挑戦」型は「雑魚狩り」型より、30日後の主スキルが **1.5倍以上**高い
  - 「1日中訓練」型は「休養を挟む」型に、7日で追い抜かれる
  - 剣術0→40（一人前）が、標準的なプレイで**約10〜15時間**
