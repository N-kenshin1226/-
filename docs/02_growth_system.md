# 02. 成長システム（本作の心臓部）

> 実装は `packages/core/growth/` に純関数として置く。
> 数値はすべて `packages/content/balance.json` に置き、コードに直書きしない。
> **この仕様の目標は「楽しい成長」であって、現実の再現ではない。** 迷ったら P1（最適ルーチンを作らない）と P5（積んだものは消えない）を優先する。

## 1. 用語

| 用語 | 定義 |
|---|---|
| **スキル** | 剣術・弓術・隠密・採掘・鍛冶・弁舌・観察など。値は `0.0〜100.0`（小数1桁） |
| **基礎能力** | 筋力・持久・敏捷・器用・知覚・精神。スキル使用の「負荷」から伸びる |
| **未定着経験 (pending)** | 行動で得た伸びしろ。睡眠で数値に変わる |
| **素質 (potential)** | スキルごとの学習効率（%）。上達で緩やかに下がり、休養・師匠・書物で回復する |
| **疲労 (fatigue)** | 0〜100の1本だけ。学習効率と行動の性能を下げる |
| **今日の追い風** | 睡眠時に抽選される、翌日だけ有効な成長補正（1〜2種） |
| **錆 (rust)** | 使わないスキルの表示値の低下。最高到達値は記憶されていて、取り戻すのが速い |
| **ランク** | 0 未経験 / 10 見習い / 25 初心者 / 40 一人前 / 60 熟練 / 80 達人 / 95 極み / 100 ??? |

## 2. 経験獲得式

```
gain = B × C(Δ) × N × P × F × W × M
```

| 項 | 名前 | 内容 |
|---|---|---|
| `B` | 基礎量 | 行動の種類ごとの値 |
| `C(Δ)` | 挑戦係数 | `Δ = 難度 − 現在のスキル値`。**逆U字**（下図） |
| `N` | 新規性 | 同じ相手・同じ行動の短時間の反復で減衰。`N = 1 / (1 + k × 直近の反復回数)`。**別分野との組み合わせ（複合行動）は新規性が回復する** |
| `P` | 素質 | `potential / 100` |
| `F` | 疲労 | `1 − (fatigue/100)^2 × 0.8` |
| `W` | 追い風 | 今日の追い風が該当すれば 1.3、逆風なら 0.8。それ以外は 1.0 |
| `M` | 修正 | 認定職・称号・師匠・書物の積（**上限 ×2.5**） |

### 挑戦係数 C(Δ)：逆U字

```
C(Δ)
1.6 |          ___
1.0 |        /     \
0.5 |      /         \
0.05|_____/           \____ 0（格上すぎ：得るものなし、怪我のリスク）
    +-----+----+----+----+----→ Δ
        -20    0   +10  +30
```

- `Δ < −20`：0.05（雑魚狩りではほぼ伸びない）
- `Δ ≈ +10`：最大 1.6
- `Δ > +30`：**0**。さらに怪我のリスクが上がる（無謀な挑戦で稼ぐことを防ぐ）
- 失敗した行動も経験になる（成功時の0.6倍）

### ミニゲームの成長は「ティア更新」でだけ大きく伸びる

- ミニゲームの結果は**作品**（品質0〜100、ティア、注文条件、特記フラグ）として**作品台帳**に記録する（`03_world_systems.md` §3）
- そのスキルで**自己ベストのティアを更新したとき**、経験は ×3
- 同じティアの反復は、経験は通常どおり（新規性で減衰する）。お金と素材だけが動く
- → 「同じ品を作り続ける」作業プレイの旨味がなくなる

### 高値帯の逓減

```
実効gain = gain × (1 − skill/110)^1.5
```

## 3. 定着：経験は「寝て起きると来る」

- 未定着経験は**睡眠時にまとめて数値へ変換**する。睡眠前は、ステータス画面に「(+1.7)」のように薄く表示する
- 1晩の定着上限 ＝ `基礎上限 × 睡眠の質`（スキルごとの上限 `nightlyCapPerSkill` と、全スキル合計の上限 `nightlyCapTotal` の両方を使う）
  - 睡眠の質 ＝ 宿のランク × 夕食（**この2要因だけ**）。`qualityMin`〜`qualityMax`（現行 0.6〜1.8）
- **ランクが低いほど大きく定着する**（F-01）：スキルごとの上限には、そのスキル値のランク帯の係数（`sleep.skillRanks`）が掛かる。未経験帯は係数 2.0、一人前以降はほぼ 1.0 —— 序盤の伸びを大きく、終盤はこれまでどおり
- 合計上限にも条件付きでランク係数が掛かる：その日の未定着の**半分以上がひとつの技能に集中**していた夜（シェア ≥ `focusShare`）は、合計上限にもその技能のランク係数が掛かる。「今日はこれだけ頑張った」日は朝の伸びも大きい。散らした日は基礎値のまま（方針間の差 §10 を守る）
- 上限を超えた分は**全量**翌日に持ち越される（F-01：以前は50%を失っていたが、頑張った分は消えない方が気持ちいい）。起床ログに「《剣術》 +2.1 は明日に持ち越し」と明示する
- ランクの境目を越えた朝は、起床ログで節目として大きく扱う（`――《剣術》は《見習い》の域に達しました。`）
- 起床ログでは、変化を**伸びの小さい順に**表示し、**最後に予想外の1行**（派生の芽、錆の回復、気配）を置く

```
━━━━━━━━━ 起床 ━━━━━━━━━
睡眠の質：良好（宿屋《麦穂亭》・シチュー）
《回避》  11.0 → 12.3  ▲1.3
《剣術》  23.4 → 25.1  ▲1.7
　《剣術》 +2.1 は明日に持ち越し
筋力 +0.2 ／ 持久 +0.3
本日の追い風：《鍛冶》の伸び ↑ ／ 格上との戦いの伸び ↓
――《剣術》は《初心者》の域に達しました。
――条件を満たしました。スキル《見切り》を獲得しました。
━━━━━━━━━━━━━━━━━━━━━━
```

## 4. 今日の追い風（最適ルーチンを崩す仕組み）

- 睡眠時に、翌日の追い風を1〜2種抽選する（例：「鍛冶の伸び↑」「格上との戦いの伸び↓」「交渉で良い客が来る」）
- 毎日最適な行動が変わり、ミニゲーム・戦闘・休息が自然に入れ替わる
- 実装は純関数1つ（`rollTailwind(state, rng)`）。抽選は直近の行動の偏りを見て、偏っている分野に「逆風」を出しやすくする

## 5. 基礎能力（身体はつくられる）

- 基礎能力はスキル使用の「負荷」から伸び、睡眠時に定着する（超回復）
  - 重い武器・重い荷物 → 筋力。長い移動 → 持久。精密な製作 → 器用。被弾 → 持久・精神
- 過負荷が3日続くと「オーバーワーク」になる。定着量が減り、怪我のリスクが上がる。休養日で解除される

## 6. 素質（potential）

- 初期値は出自で決まる（80〜130%）。転生時の継承で補正がかかる（`06_endgame.md`）
- スキル値が1上がるごとに、現在値の約1%下がる
- 回復手段：休養日、師匠（お金と日数）、書物（特定のスキル帯だけ倍率がかかる）

## 7. 錆（取り戻す快感の供給源）

- 最後に使ってから14日経つと、表示値が1日0.1ずつ下がる。**下限は最高到達値の70%**
- 最高到達値までの再習得は**×3速**。演出の主役はこちら（「身体が覚えている」）
- **脳の容量**：合計スキル値が閾値を超えると、使っていないスキルの錆が早まる（ソフトキャップ）

## 8. 学び方の種類

| 方法 | 効果 |
|---|---|
| 実践 | 基本 |
| 訓練 | 安全だが、挑戦係数の上限が 0.6 |
| 師匠 | 素質の回復＋一定期間の倍率。お金と日数がかかる |
| 書物 | 一定のスキル帯でだけ倍率がかかる |
| 見取り稽古 | 敵やNPCの技を《観察》しながら耐えると、理解度が溜まる。100%で習得条件を満たす |

## 9. 派生スキル・称号

- **派生スキル**：複数のスキル値＋行動パターンで条件を満たす。**突出したスキルの上限は、他分野と組み合わせた派生でだけ開く**（一点特化だけが最適解にならないようにする）
- **称号**：行動ログのカウンタと条件式で判定する。効果は小さく、フレーバー重視
- 未達の条件は表示しない。ただし2周目以降は、図鑑の空き枠に系統のヒント（分野名だけ）を出す
- 条件はデータ上はすべて列挙し、CIで「到達可能か」を検査する（UI側だけで伏せる）

## 10. 検証：バランスCIゲート（M0で最初に作る）

`pnpm sim:growth` と `pnpm sim:retention` を CI で必ず走らせる。

**ボットの行動方針**（4種）：単一ルーチン（最適化型）／多様型／ランダム／簡易判定のみ型

| 指標 | 合格の条件 |
|---|---|
| 到達帯 | 標準プレイ3時間で主スキル25〜40、10〜15時間で40（一人前） |
| 方針間の差 | 単一ルーチン型と多様型の成長差が **1.3倍以内** |
| 簡易判定の効率 | 簡易判定のみ型の収益が手動の **80%以下**、経験は **50%以下** |
| 称号の到達可能性 | 全称号・全派生が、いずれかのボットで到達できる |
| 新規性の供給 | 開始から15分・1時間・3時間・8時間の各時間帯に、初体験イベントが基準件数以上ある（03 §6） |
| 作業化 | 同じ行動の連続回数の最大値が基準以下 |

基準を割ったらCIを落とす。Devinの変更が静かにゲームを壊すのを防ぐ、唯一の機械的な手段。
