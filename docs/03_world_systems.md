# 03. 世界とシステム

## 1. 世界生成（P4：この世界は一つだけ）

- **世界シード**から次を生成する。Caves of Qudの「出来事を先に生成し、理由を後付けする」方式を参考にする
  - 地方の構成（ノードグラフ。街・森・洞窟・遺跡など）
  - **歴史**：過去の王・英雄・災厄を5〜8件生成する。遺跡・書物・NPCの昔話はこの歴史を参照する
  - **ユニークモンスター**：外見・性格・弱点の組み合わせ。各個体は1周に1体だけ
  - **ユニークシナリオ**：テンプレート＋歴史上の人物で組み立てる。発火条件を満たした1回だけ起きる
- 手作りで固定するもの：開始の街、チュートリアル、メインの謎の骨格
- 同じシードなら同じ世界（決定論的）。掲示板で「シード共有」ができる余地を残す

### 探索の表現
- MVPでは**ノード移動＋エリア内のイベントカード**（テキストアドベンチャーに近い）にする
- 将来はエリアごとに2Dの見下ろしマップへ拡張できるよう、ロジックと表示を分ける

### 条件付き出現（隠し要素）
ゲーム内の時刻・天候・月齢・プレイヤーの状態・所持品の組み合わせで発生させる。

```jsonc
{
  "id": "hidden.belfry_ghost",
  "where": "town.start.belfry",
  "when": { "time": ["night"], "moon": "new", "weather": "any" },
  "requires": { "flag": "read.book.old_chronicle_p3" },
  "spawn": "npc.ghost_bellringer"
}
```

## 2. 戦闘（P3：知識と腕が効く）

**「予兆を読む」CT制ターンバトル**。

- 時間はtick単位で進む。行動ごとにCT（チャージタイム）があり、敏捷や武器の重さで変わる
- 敵は大技の前に**予兆**を出す。予兆テキストの解像度は《観察》スキルで変わる
  - 観察が低い：「狼が唸っている」
  - 観察が高い：「狼が後ろ足に重心を移した――**飛びかかり**（2tick後）」
- プレイヤーは防御・回避・割り込み・カウンター・逃走・アイテム・位置取り（前／後）で対応する
- **敵の行動パターンは固定ルールで書く**ので、プレイヤーが学習できる（シャンフロの「パターンを読む」快感）
- 部位：頭・胴・腕・脚。部位へのダメージで一時的なデバフがかかり、怪我として数日残る（リアリティ）
- 死亡時：街でリスポーンし、デスペナルティとして**未定着経験の50%を失う**＋所持金の一部を落とす。数値は下がらない
  → 「死ぬと悔しいが、積み上げは失わない」

## 3. 称号・実績の条件DSL

条件はデータ（JSON）で書き、コアは汎用の評価器だけを持つ。

```jsonc
{
  "id": "title.hundred_wolves",
  "name": "百狼斬り",
  "hidden": true,
  "condition": { "counter": "kill.species.wolf", "gte": 100 },
  "effect": { "damageVs": { "wolf": 1.05 } },
  "message": "称号《百狼斬り》を獲得しました。"
}
```

- 条件演算：`counter / flag / skill / stat / time / and / or / not / within(期間)`
- 行動はすべて **イベントログ**（`ActionEvent`）として流し、カウンタ更新・称号判定・掲示板ネタ抽出は購読者として実装する

## 4. 「世界初」とワールドアナウンス（P2）

- **発見台帳**：初討伐・初到達・初習得・初製作を、プレイヤーとNPC冒険者の区別なく記録する
- プレイヤーが世界初を取ると、画面全体に演出を出す：
  > ――ワールドアナウンス：プレイヤー《ケンシン》が、ユニークモンスター《沈黙の鐘守》を初討伐しました。
- NPC冒険者に取られた場合も通知する。**取り逃しの悔しさも体験の一部**

## 5. NPC冒険者シミュレーション（ソロでMMOの空気を出す）

- 200〜500人の「プレイヤー」を軽量にシミュレートする（個別の戦闘はせず、確率的な進行モデルを使う）
  - 各NPCは方針（攻略勢・生産勢・PK勢・のんびり勢）、実力の曲線、所属ギルドを持つ
  - 1日ごとに「どのコンテンツに挑み、成功したか」を抽選で決める。成功すると台帳に載る
- **ネームドのライバル**：5〜10人が個性と口調を持ち、街で会話したりパーティを組んだりできる
- 攻略の進行速度はプレイヤーの進行に緩く追従させる（RimWorldのストーリーテラー的な調整）。先に行かれすぎず、置いていかれもしない

## 6. 攻略掲示板（本作の看板機能）

- ゲーム内UIで閲覧できるフェイク掲示板。ラノベの「掲示板回」の再現
- スレッドは**ワールドの出来事から生成**する（テンプレート＋変数＋NPCごとの口調）
  - 世界初の報告、ユニークの目撃情報、考察スレ（派生スキル条件のヒント）、雑談、愚痴（「疲労システムいらんだろ運営」）
- プレイヤーの行動が話題になる：「【速報】例の名無しソロ、また何かやった」
- **ヒントの供給源**も兼ねる：書き込みの一部は、隠し要素の条件を半分だけ正しく語る（考察の楽しさ）
- 将来はLLMで書き込みを増やすオプションを付ける。MVPではテンプレートのみ（`04_tech_and_devin.md` を参照）

## 7. 経済・製作（最小限から）

- MVPでは素材の採集 → 製作 → 売却の一方向だけにする。製作品の品質は《鍛冶》と素材で決まる
- 製作品にも「世界初」がある（初めて作った品に製作者名が刻まれる）

## 8. 時間

- ゲーム内の1日は、実時間30〜60分ほどのプレイに相当する（行動ごとに時間が進む）
- 宿で寝ると翌朝まで進む。待機・スキップは常に可能
- 曜日・季節・月齢がある（隠し要素の条件として使う）
