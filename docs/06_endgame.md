# 06. 寿命・転生・エンドコンテンツ

## 1. 一生＝1周（背骨）

- キャラクターは年を取る（15歳ごろから）。若い頃は基礎能力が伸びやすく、歳を取ると技と知恵の伸びが良くなる
- **強制リセットはしない**：
  - 引退はいつでも選べる。早く引退しても伝記は書かれる
  - 強制で死ぬのは老衰だけ。かなり前から「老いの兆候」イベントで予告する
  - 子や弟子に継承して延長することもできる（M4以降）
- 引退・死亡のとき：**伝記の自動生成 → 年代記への記録 → 継承 → 転生**（新しいシードの世界へ）

## 2. 継承（数値インフレを起こさない）

引き継ぐのは次の3つだけ。

| 継承するもの | 内容 |
|---|---|
| 素質の補正（小） | 前世の最高到達値の一部を、次の周の素質の補正に変換する（例：最高値の10%を素質%に加算。上限あり） |
| 称号 | 一部の称号を「前世の記憶」として保持する |
| 遺物1個 | 前世の作品台帳から1つ選び、次の世界に名品として現れる |

- **前世が伝説として登場する**（M3では最小版）：新しい世界の年代記に、前世の名・二つ名が一行載る
- M4以降：前世の技が、次の世界の師匠NPCや失われた書物として現れる
- 2周目の序盤を楽にする：前世の縁で、開始時の立場や出自を選べる

## 3. エンドコンテンツ（3層）

### A. 人生の頂点ルート（人生の大きな目標）
英雄（災厄の討伐）／剣聖（武術大会の連覇と奥義）／商王（経済圏の支配）／領主（領地経営から建国）／大賢者（禁書と世界の真理）／伝説の職人（神器の製作）

- **複数のルートを同時に追ってよい**（剣聖をしながら商人も）。ルートに章立ての物語は持たせない
- 「3ルート達成で真エンド解放」は廃止。**真エンドは、その世界の危機を解決して得る**（`08_world_crisis.md`）
- 最初に見せるのは4ルートだけ（英雄・剣聖・伝説の職人・大賢者）。2ルート（商王・領主）は伏せて、噂で匂わせる
- 実装：6ルートすべて実装済み（pinnacles.json。英雄は X-39 で追加 —— 危機の接点・打診・決着・勝利がそのまま段になる）

### B. やり込み（終わりなし）
- **無限深層ダンジョン**：時間制限＋自己ベスト（Diablo 3のGreater Riftを参考にする）。短時間プレイと相性が良い
- 強化版ユニークとの再戦、図鑑・称号のコンプリート

### C. 周回の変化
- **運命の傾向**：周の開始時に3択で選ぶ（穏やか／戦乱／飢饉）。変数は1軸だけにする（バランス検証を発散させない）
- **誓約**：難度を上げる条件を自分で積み、条件ごとに称号を得る（Slay the SpireのAscension、Hadesの誓約を参考にする）。最初は難度の修飾子5個から
- 年代記は周回をまたいで厚くなる。過去の人生の一覧がコレクションになる

## 4. 参考にしたゲームと根拠
- Hades：死ぬたびに進行が残る → 引退・死亡でも必ず確定の報酬を出す
- Crusader Kings 3：継承でプレイが続く → 子や弟子への継承
- Dwarf Fortress「Losing is Fun」：失敗も物語になる → 死や破産を年代記に残す
- RimWorld：ストーリーテラー → 運命の傾向
