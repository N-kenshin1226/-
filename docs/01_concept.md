# 01. コンセプト

## 1. 一言で

**「行動したことだけが強さになる。世界はそれを見ていて、記録し、語り継ぐ」**

レベルを上げて数値を振るゲームではない。剣を振れば剣術が、重い荷を運べば筋力が、
鉄を打てば鍛冶が伸びる。そして成長は**寝て起きた朝に定着する**。
朝のステータス確認が、ラノベの「ステータスオープン」の瞬間になる。

## 2. 世界観

- **王道の異世界ファンタジー**：剣と魔法、魔物、迷宮、ギルド、冒険者ランク、加護とステータス。なろうの「異世界ステータス系」の標準的な世界（固有の味付けは今後決める）
- **加護の世界**：この世界では誰もが神の「加護」を受けており、ステータスが見え、システムメッセージが聞こえる。なろうの定番の形で、ゲーム的な表示に作中での理由を付ける
- 文体は二層構造：**淡々とした機械口調のシステムメッセージ**と、**人間くさい噂・新聞・NPCの台詞**
- **主人公は平凡**：転生すること以外は普通の人。選ばれし者ではなく、運も血筋も特別ではない。世界にはシードごとに違う危機があり、ほかの人々も救おうとしている（`08_world_crisis.md`）
- ダーク寄りにはしない。疫病・戦乱は「世界の出来事」として起きるが、主題は成り上がりと成長

> MMO設定（VRMMOの中という設定）は廃止した。仕組みは次のように置き換える。
> 掲示板 → 噂・新聞／NPCプレイヤー → ライバル・ランキング／ワールドアナウンス → 年代記／死に戻り → 教会での蘇生（代償あり）

## 3. 5本柱（デザイン判断に迷ったらここに戻る）

| # | 柱 | 意味 | やらないこと |
|---|---|---|---|
| P1 | **行動＝成長** | 経験値やレベルの割り振りはない。行動の量・質・難度から伸びる | 毎日同じ「最適ルーチン」が正解になる設計 |
| P2 | **世界はあなたを見ている** | 称号、派生、システムメッセージ、NPCの態度の変化、新聞、年代記 | 何をしても反応がない状態。逆に、通知の乱発（通知は予算で管理する） |
| P3 | **知識と腕が効く** | 予兆を読む戦闘、ミニゲームの腕前、隠し条件。スキルは「操作を助ける」形で効く | 数値だけで結果が決まること |
| P4 | **生き方は自由** | 立場×職業の2軸、人生目標カタログ、カタログ外の道も条件を満たせば開く。生き方は「選んだ型」ではなく「実際にしたこと」の積み重ね。頂点ルートや職業は近道であって、何かを遊ぶための条件にしない | 白紙の放置（何をすればいいか分からない状態） |
| P5 | **積んだものは消えない** | 錆は取り戻す快感に、死は年代記に、一生は次の世界の伝説に | 積み上げを破棄させること。強制リセット |

### 「リアリティ」の線引き

リアリティは**罰ではなくボーナス**として設計する（寝れば定着、食べれば強化）。

- ✅ やる：疲労（1本）、睡眠による定着、怪我の一時的な弱体化、緩い錆、相手に応じた学びの量、師匠・書物、加齢による伸び方の変化
- ❌ やらない：空腹の手動管理、耐久修理の連打、移動に実時間がかかること
- **毎日気にする管理項目は常に3つまで**（疲労・所持金・今日の追い風）

## 4. コアループ

```
 ┌───── 1日（約15分。睡眠で必ず区切る） ─────┐
 │ 朝：起床ログ（昨夜定着した成長＋今日の追い風）│
 │  ↓                                          │
 │ 計画：依頼・噂・新聞・人生目標を見る            │
 │  ↓                                          │
 │ 行動（3〜5回）：仕事／探索・戦闘／交渉／        │
 │              訓練／人に会う                     │
 │  ├ 日常の行動は簡易判定ですぐ終わる             │
 │  ├ 勝負所（1日1〜2回）でミニゲームが出る        │
 │  ├ 経験は「未定着」として溜まる                 │
 │  └ 作品・偉業は台帳に記録                      │
 │  ↓                                          │
 │ 夜：宿で寝る → 定着 → セーブ                   │
 └──────────────────────────────────────────────┘
   季節（約15〜30分）：ランキングの更新、祭り・相場・世界の出来事
   一生（30〜50時間）：立場の上昇、認定職、頂点ルート
   引退 → 伝記 → 転生：次の世界で前世が伝説になる（06_endgame.md）
```

- **短時間**：1日＝約15分で完結する。睡眠でセーブ
- **長時間**：日 → 季節 → 年と自然につながる。季節ごとに新しい出来事がある

## 5. 体験として目指す瞬間（「これが出たら成功」）

1. 朝、ステータスを開くと《剣術 23.4 → 25.1》。最後の1行だけ予想外の変化がある
   > ――条件を満たしました。スキル《見切り》を獲得しました。
2. 何日か前から、ステータス画面の隅に一行だけ出ている
   > ――何かが、噛み合いかけている。
3. 自分の打った剣が新聞に載る。本人の意図とは違う読まれ方で
   > 【王都新報】辺境の鍛冶場に謎の名工現る　〈鬼をも斬る〉と評判
4. 門番の口調が、立場が上がるにつれて変わっていく（タメ口 → 丁寧語 → 平伏）
5. 雑魚狩りでは伸びない。少し格上に挑むと一気に伸びる。格上すぎると何も得られず怪我をする
6. 1か月使わなかった弓は数値が落ちている。ただし取り戻すのは早い
   > ――身体が覚えている。《弓術》の再習得速度が上昇しています。
7. 2周目。新しい世界の年代記に、前世の自分の名と二つ名が「伝説の鍛冶師」として載っている
