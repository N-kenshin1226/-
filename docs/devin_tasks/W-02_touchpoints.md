## タスク: [W-02] 接点（危機が日常に混ざる）と寄与

### やること（仕様 §5）
- 危機の段階に応じて、既存の遊びに**接点**を混ぜる：注文（鍛冶）、輸送・相場（商い）、防衛・退治・遠征への誘い（戦い）、避難民・仲裁（交渉）、調査・写本（学び）
- 新しい遊びは作らない。既存の注文・依頼・戦闘・ミニゲームの勝負所・交渉・書物に「危機のタグ」を付けて出す
- 接点の結果を、該当分野の**備え**への寄与として加える。普通に暮らす範囲では、世界全体の一部にとどまるよう調整する
- 断っても不利益なし（評判も下げない）

### 受け入れ基準
- [ ] 各生き方（鍛冶・商い・戦い・人脈・学び）に接点が出るテスト
- [ ] 寄与が備えに反映され、決着の成否に影響するテスト

### 共通
- 仕様は **`docs/08_world_crisis.md`** が正。`AGENTS.md` の絶対ルールと完了の定義を守る
- **世界を主人公に背負わせない**（仕様 §1）。危機を主人公向けのクエストや「やるべきこと」の一覧として見せない。接点は断っても不利益なし
- 数値は `balance.json`、データは zod スキーマ付きの JSON
- テストは公開サンプル（`packages/content/crises/sample.json`）で書く。**`packages/content/hidden/` の中身を読んだり、PRの説明・コミットメッセージ・報告に書いたりしない**（読み込む仕組みだけ作る）
