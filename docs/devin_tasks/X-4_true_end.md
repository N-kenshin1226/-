## やること
1. **3ルート目を追加する**：`大賢者`（禁書と世界の真理）。4段の条件鎖を
   pinnacles.json に追加する。条件は既存の条件DSL（flag/counter/skill/within/
   work/time）で表せる語彙だけで組み、足りなければ DSL に最小限の語彙を足す
   （ただし evaluate のテストを必ず追加）。「世界の真理」は見聞録の繋がり
   （`lore` の connection flag）か書物の知識フラグで表現するのが保守的。
   禁書が必要なら books.json に flag 付きの書物を追加してよい
   （既存書物は flag を持たないものが多いので注意）
2. **真エンドの解放判定**：年代記（chronicle.lives の `pinnacles` 配列を横断した
   一意のルートID）が累計3種に達したかを返す読み取り関数を core に追加する
   （例: `trueEndUnlocked(chronicle, routes)`）。GameState は変えない
   ——年代記の持つ `pinnacles` を数えるだけでセーブ不変のはず
3. **真エンドの見せ方（保守的）**：解放後に人生を終える（引退・老衰）とき、
   継ぎ方の選択画面に「真エンド」の選択肢か別画面を出し、専用の語りテキスト
   （narration.json に新しいリクエスト種別かテンプレ節）を表示する。
   解放は通知（notice ランク S）でも知らせる。仕様に本文の定義がないため
   「真エンドの語り」は最小限の骨格にとどめ、PRの判断ログに「要確認」と書く
4. CLI（packages/sim）と Web（apps/web）の両方に接続する
