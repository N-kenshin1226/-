## 実装メモ（X-4 作業分）

**範囲**：冒頭の「範囲変更」どおり、§1 の大賢者ルート追加だけを実装した。
真エンドの解放判定・通知・画面は一切実装していない（W-01〜W-05 の世界の危機
設計に置き換え。`docs/08_world_crisis.md`・W-*/C-01 チケットには触れていない）。

**ルート設計（pinnacles.json `great_sage`、4段 B/A/A/S）**：
1. 読書の虫（B）— `counter action.read ≥4`＋観察20。readAtom/readBook は
   どちらも `actionPerformed kind:"read"` を出すので既存カウンタで数えられる
2. 鑑定の眼（A）— 鑑定45＋`work appraisal tierGte3`＋読了累計7。
   鑑定の仕事は `orders.json order.relic_check`（出土品の真贋）が実在するため
   シムだけでなく実プレイでも到達可能
3. 禁書の探索（A）— `flag found.taboo_codex`＋鑑定65＋弁舌50。
   旗は見聞録の新アトム `rumor.taboo_codex`（禁書の噂）の `unlock` で立つ
   ——「まず噂で匂わせる」流れ。canon・fact は追加していない（rumor なので）
4. 世界の真理（S）— `flag knows.world_truth`＋鑑定90＋観察75。
   旗は新書物 `book.taboo_codex`（封じの写本・150G）の `flag` で立つ。
   チケットの保守的案どおり「書物の知識フラグ」で表現した

新しい語彙は条件DSLに足していない（flag/counter/skill/work の既存語彙のみ）。
数値は既存2ルートの型に合わせた（頂点は主スキル90＋副条件、段ごとに技能が
20→45→65→90 と上がる）。称号 `title.great_sage` は titles.json に追加し、
`condition: {flag: "pinnacle.great_sage.apex"}` ——突合検証（validate.ts）どおり。

**sim 到達性の判断**：`makePinnacleBot` を拡張して「読む系の条件」を解ける
ようにした（「対象外」扱いにはしなかった）。理由：頂点レポートに段ごとの
到達日数が出ることがこのルートの実用的な検証になるため。ボットは
flag → アトム（無料）→ つながり用アトム → 書物（購入＋読了、不足時は
最高技能で仕事して稼ぐ）、`action.read` → 未読アトム → 所持書物 → 購入
の順に進める。結果：sim:growth で `読書の虫=8日目 / 鑑定の眼=26日目 /
禁書の探索=58日目 / 世界の真理=111日目` と全段到達を確認（剣聖148日・
職人44日の中間あたり）。

**残課題・注意**：
- 封じの写本は books.json の普通の商品（書店《古紙堂》に並ぶ）。禁書を
  「買えるが高い」扱いにした。将来「店に並ばない禁書」にするなら
  書店の陳列フィルタが別途必要（本タスク範囲外）
- `rumor.taboo_codex` は噂アトム（事実を明かさない）。「世界の真理」の
  物語ペイロードは readText の一文だけで、canon には背理を残さない
- 仕様の「最初に見せるのは4ルート。2ルートは伏せて噂で匂わせる」は
  未実装のまま（ルート数が4に足りないためチケット記載どおり範囲外。
  現在3/6ルート）
