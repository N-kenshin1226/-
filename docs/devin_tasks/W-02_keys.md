## タスク: [W-02] 鍵と3つの道（自分の腕・依頼・協力）

### やること
- 鍵（分野：力・技・縁・財・知）と、各鍵の道を実装する。**各鍵に道を3つ以上**
  - 自分の腕：既存の戦闘・ミニゲームの勝負所・交渉につなぐ（新しい遊びは作らない）
  - 依頼：NPCに頼む。お金・素材・関係値がかかる。期間をおいて結果が出る（失敗もありうる）
  - 協力：ライバルや勢力と組む。縁（評判・交渉）が要る
- **公示**：段階が進むごとに、必要な鍵を世間に公開する（新聞・掲示に1件ずつ）。公示前でも、関連する見聞録の断片を持っていれば鍵が分かる（近道）
- 頂点ルートの到達で、関連する道が楽になる効果（例：剣聖→力の鍵の自分の腕、商王→依頼の費用）
- 鍵がすべて揃うと危機が解決する（誰が揃えてもよい）

### 受け入れ基準
- [ ] すべての鍵に3つ以上の道があり、それぞれ単体テストで達成できる
- [ ] 公示のタイミングと、見聞録による先取りのテスト
- [ ] 主人公が一つも鍵を取らなくても、NPCが揃えれば解決する（W-03の後に結合テスト）
