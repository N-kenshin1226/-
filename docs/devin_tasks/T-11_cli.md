## タスク: [T-11] CLIで遊べる版

### 目的
UIを作る前に、オーナーが手で遊んで「起床ログが気持ちいいか」を判断するための版。

### 読むもの
`docs/01_concept.md` §4〜5、`docs/02_growth_system.md` §3（起床ログの例）、`AGENTS.md`（文体）

### 作るもの（`packages/sim/src/cli/`、`pnpm play:cli`）
- 対話式のターミナルゲーム：メニューから行動を選ぶ（訓練：スキルと難度を選ぶ／休む／寝る：宿と夕食を選ぶ）
- 状態表示：日付・時刻帯・疲労・所持金（今は固定値）・今日の追い風
- **起床ログを 02 §3 の例の見た目で表示する**（罫線、▲、システムメッセージの書式）
- 称号の獲得時にシステムメッセージを表示する
- セーブ：寝るたびに `~/.trace/save.json` へ自動保存。起動時に続きから遊べる
- 表示用の文はテンプレートとして `packages/content/text/cli.json` にまとめる（直書きしない）

### 受け入れ基準
- [ ] 3日分を通して遊べる（Playwright ではなく、入力列を流し込む自動テストで確認）
- [ ] セーブとロードで続きから遊べる
- [ ] 起床ログの表示のスナップショットテスト
- [ ] PRに、3日分遊んだときの画面出力の全文を貼る（オーナーがPRだけで雰囲気を確認できるように）

### 共通
- `AGENTS.md` の「絶対ルール」と「完了の定義」を守る
- ゲームの数値は `packages/content/balance.json` に置き、zodスキーマ（`balance.schema.ts`）も更新する
- 乱数を使うテストはシードを固定する
- PRの説明に「判断ログ」節を設け、仕様にない判断を1行ずつ書く
