## タスク: [P-01] 場所と移動（画面転換）

### 問題
- 何をするにも同じ街の画面のメニューから選ぶだけで、場所が変わる感覚がない（画面転換がない）

### やること
1. **場所の構造**を入れる。街は複数の**場所**でできている（例：鍛冶場、市場、酒場、ギルド、教会、宿、街の門、自宅）。街の外には森・旧街道・湖などの**地域**がある
2. **地図の画面**：街の見取り図から場所を選んで移動する。街の外へは門から出る
3. **場所ごとの画面**：場所ごとに背景（情景）・そこにいる人・できる行動が違う。今の行動は、それぞれ合う場所に移す（仕事→鍛冶場やギルド、書店→市場、師匠→それぞれの居場所、新聞→酒場や宿でも読める、など）
4. **画面転換の演出**：移動時のフェード／ワイプ、戦闘に入るときの暗転と揺れ、眠るときに暗くなって朝に明るくなる、など。演出は飛ばせる
5. **時間帯で景色が変わる**：朝・昼・夕・夜で背景の色と灯りが変わる。天候（X-13）も背景に反映する（雨・霧など）
6. 街の中の移動は行動を消費しない（または小さく）。街の外への移動は行動を消費する
7. キーボード操作（↑↓・Enter・Esc）とマウスの両方で移動できる

### 受け入れ基準
- [ ] 地図 → 場所 → 行動 → 地図、の移動ができ、場所ごとに背景と行動が変わる（e2e）
- [ ] 移動・戦闘開始・睡眠で画面転換の演出が入る
- [ ] 時間帯と天候で背景が変わる
- [ ] 既存の機能が、どこかの場所から全部たどれる

### 共通
- 背景：オーナーが遊んだ感想 **「ランダム性がなければリアルじゃない」「音も欲しい」「行動の種類が少ない」「画面転換がない」**。このタスクはその解消が目的
- `docs/design/` の見た目のルールを守る。新しい場所の背景は、デザイン見本と同じ作り（SVGの情景レイヤー）で描く
- 乱数はすべてシード付きRNG（`rng/`）で。テストとsimは決定論的に保つ
- 数値は balance.json / theme.ts に置き、オーナーが調整できるようにする
- バランスCIゲートが落ちる場合は、閾値ではなく数値で合わせる
- PRに、変更前と変更後のスクリーンショットを添付する
