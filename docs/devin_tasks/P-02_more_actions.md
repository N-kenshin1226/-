## タスク: [P-02] 行動の種類を増やす

### 問題
- できることが「仕事・鍛錬・狩り・深層・師匠・書店…」に限られ、生活の手触りが薄い

### やること（P-01 の場所に配置する。新しい遊びは、既存の3エンジン・戦闘・交渉・出来事に乗せる）
- **散策**：街や地域を歩く。出来事（F-05）・人との出会い・拾い物・見聞録の断片が起きる
- **人と過ごす**：NPCと話す・一緒に飲む・贈り物をする。関係値が育ち、依頼・紹介・師事・同行につながる
- **市場で売買**：作った品や採集物を売る、素材を買う。相場が日によって動く（R-01）
- **採集**：森・川・山で薬草・木の実・鉱石・魚などを集める（場所と季節・天候で取れる物が変わる）
- **料理**：集めた食材で料理する（駆け引き／タイミングのエンジン）。食べると翌日の調子や睡眠の質に効く
- **賭け事**：酒場のサイコロ・カード（駆け引きのエンジン）
- **祈る・寄付する**（教会）、**依頼掲示板**（ギルド）、**休日の過ごし方**（自宅：読書・手入れ・昼寝）
- **旅**：隣の町へ行く（数日かかる。道中の出来事。町ごとに相場・注文・人が違う）。MVPは隣町1つ
- 行動ごとに伸びるスキル・基礎能力を決める（新しいスキルを足す場合は skills.json に）

### 受け入れ基準
- [ ] 上の行動がすべて遊べ、それぞれ何かが伸びる・何かが手に入る
- [ ] sim の「どの生き方にも接点」「新規性の供給」などのゲートが通る

### 共通
- 背景：オーナーが遊んだ感想 **「ランダム性がなければリアルじゃない」「音も欲しい」「行動の種類が少ない」「画面転換がない」**。このタスクはその解消が目的
- `docs/design/` の見た目のルールを守る。新しい場所の背景は、デザイン見本と同じ作り（SVGの情景レイヤー）で描く
- 乱数はすべてシード付きRNG（`rng/`）で。テストとsimは決定論的に保つ
- 数値は balance.json / theme.ts に置き、オーナーが調整できるようにする
- バランスCIゲートが落ちる場合は、閾値ではなく数値で合わせる
- PRに、変更前と変更後のスクリーンショットを添付する
