## タスク: [F-04] 戦闘に駆け引きを

### 問題（実測）
- Enter を押し続ける（攻撃の連打）だけで狼に勝てた。与ダメージは毎回 7、被ダメージも毎回同じ
- 「予兆が見える」と出ても、対応する意味が薄い。敵の姿もない

### やること
1. **予兆に対応しないと痛い**ようにする：大技は防御・回避で大きく減らせ、対応しないと大きな傷。正しく対応するとカウンターや隙が生まれる
2. **ダメージに揺らぎと会心**：同じ攻撃でも幅がある。会心・急所は演出つき
3. **敵の姿**：シルエット（SVGでよい）を画面に出し、予兆で構えが変わる。HPゲージ（敵・自分）
4. 戦闘のテンポ：行動ごとに短い演出（斬撃の線、揺れ、数字が飛ぶ）
5. 格上の敵では、連打では勝てず、予兆への対応が必要になるよう調整する

### 受け入れ基準
- [ ] 連打だけでは「挑戦差 15 以上」の敵に勝てない。予兆に対応すれば勝てる（sim か単体テストで確認）
- [ ] 敵の姿・HPゲージ・ダメージ表示がある

### 共通
- 背景：オーナーが実際に遊んだ感想は **「刺激があんまりない」**。このタスクの目的は、それを直すこと。仕様の細部より「遊んで気持ちいいか」を優先してよい（変えた点は判断ログに書く）
- `docs/design/` の見た目のルールを守る。演出の数値（時間・大きさ・音量など）は theme.ts か balance.json に置き、オーナーが調整できるようにする
- バランスCIゲート（`pnpm sim:*`）が落ちる場合は、閾値ではなく数値で合わせる。仕様の意図とぶつかる場合は判断ログに「要確認」
- PRに、変更前と変更後のスクリーンショット（動きがあるものは数枚の連続画像）を添付する
