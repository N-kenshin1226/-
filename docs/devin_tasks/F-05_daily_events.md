## タスク: [F-05] 日々の出来事と、驚き

### 問題
- 毎日が「メニューから行動を選ぶ」の繰り返しで、予想外のことが起きない

### やること
1. **出来事**：1日に0〜2回、行動の合間に小さな出来事が起きる（旅人に道を聞かれる、喧嘩の仲裁、拾い物、珍しい客、師匠の気まぐれ、天候の急変…）。選択肢つきで、結果に幅がある（小さな得・損・縁・手がかり・ごく稀に大当たり）
2. **リスクのある選択**：安全な選択と、賭けの選択を並べる（例：怪しい商人の掘り出し物を買う／見送る）
3. 出来事は見聞録の断片・NPC・危機の接点とつながるものを混ぜる（`docs/07_story.md`、`docs/08_world_crisis.md`）
4. 出来事のデータは JSON（条件 DSL で出現条件を書く）。最初は30件。同じ出来事が短期間に繰り返さない
5. **日常の注文は簡易判定を標準にする**。注文一覧の「勝負所」は1日1〜2件に絞り、目立つ札を付ける（今は釘の束にも「勝負所です」と出ている。`docs/03_world_systems.md` §2 の「使い所の原則」）

### 受け入れ基準
- [ ] 普通に遊ぶと、3日に1回以上は出来事が起きる（sim で確認）
- [ ] 注文一覧の勝負所が1日2件以下

### 共通
- 背景：オーナーが実際に遊んだ感想は **「刺激があんまりない」**。このタスクの目的は、それを直すこと。仕様の細部より「遊んで気持ちいいか」を優先してよい（変えた点は判断ログに書く）
- `docs/design/` の見た目のルールを守る。演出の数値（時間・大きさ・音量など）は theme.ts か balance.json に置き、オーナーが調整できるようにする
- バランスCIゲート（`pnpm sim:*`）が落ちる場合は、閾値ではなく数値で合わせる。仕様の意図とぶつかる場合は判断ログに「要確認」
- PRに、変更前と変更後のスクリーンショット（動きがあるものは数枚の連続画像）を添付する
