## タスク: [F-03] ミニゲームに動きと手応えを

### 問題（実測）
- 鍛冶は「槌の拍に合わせて Enter。5打」と出るが、**拍が画面に表示されない**（静止した●が5つと「打つ」ボタンだけ）。何に合わせればいいか分からない
- 表示どおり Space を押しても反応しなかった（0 命中のまま）
- 最初にカーソルが「やめる」に乗っている（誤って中断しやすい）

### やること
1. **タイミング系（鍛冶・演奏・釣り）**：動く拍を描く（縮む輪、左右に振れる針など）。判定窓をゲージ上に見せる。命中で火花・音・画面の小さな揺れ、外れで鈍い音。連続命中のコンボ表示
2. **盤面系（採掘・鑑定）**：マスを開ける手応え（ひびが入る、鉱石が光る）。危ないマスを開けたときの演出
3. **駆け引き系（交渉）**：相手の表情（シルエットの変化でよい）と、押している・押されているのゲージ
4. Space・Enter・クリックのどれでも操作できる。最初のカーソルは「始める」側に置く
5. 結果画面：品質の数字をカウントアップ、ティア更新・会心は F-02 の演出で
6. 判定窓・速さ・揺れの大きさなどは balance.json / theme.ts に置く（オーナーが手触りを調整する）

### 受け入れ基準
- [x] 3種類のエンジンすべてで、何に合わせて・何を狙って操作するかが画面を見て分かる
- [x] キーボード（Space/Enter）とクリックの両方で操作でき、e2e で命中を確認できる
- [x] 最初のカーソルが「やめる」に乗っていない

### 実装メモ（2025-10-27）
- **タイミング系**：`BeatRail` が「拍の流れるレール」を描く――針（現在時刻）・判定窓（拍の周りの帯、窓に入ると緑に灯る）・外から的へ縮む輪・解いた拍の印（命中＝金の●／外れ＝珊瑚の×）。命中で `SparkBurst`（散り方は拍の番号で決まる、乱数なし）＋命中音＋ `ShakeBox` の小さな揺れ、外れは乾いた一拍（miss 音）。連続命中は「{n}連続命中」のコンボ表示。押すタイミングは `data-armed` で外からも読める（e2e の押し所）
- **盤面系**：開けたマスに一瞬の演出（鉱石＝金の閃き `mg-rev-ore`／岩＝珊瑚のひび `mg-rev-rock`＋揺れ／空地＝じんわり `mg-rev-empty`）。空地の手がかり数は core が返した `lastHint` をそのマスの中に小さく残す（`mg-cell-hint`、隠し情報は増やさない）。鉱石は coin 音＋「鉱脈だ！」の浮き文字、岩は miss 音＋警告文
- **駆け引き系**：`OpponentFace`（シルエット SVG、局面で目・口・傾きが変わる：互角／焦り／にやり／×目／ほくそ笑み）＋ `PushGauge`（押し合いの針、HP差で中央から寄る）＋ `ClashLine`（出した札×相手の札の応酬を1行で見せる）
- **品質の積み上げ**：`QualityMeter` が core の `result()` を各手に映す（数がめくれる `CountUp`＋帯が伸びる。目標品質の刻み付き、届くと緑に）
- **結果画面**：`ResultReveal`――品質のカウントアップ＋旗（会心・失敗作など）の章が順に飛び込む。クリックか Enter で即確定（スキップ可）。ティア更新・会心の刻印・通知は F-02 の演出のまま
- **操作**：遊んでいる間は皮がキーを握る（`useHotkeys`：Space/Enter＝打つ・掘る・出す、矢印＝マス・札のカーソル、Esc＝やめる、交渉は数字キーでも出せる）。その間コマンド列は `auto=false` でキーを受けない。結果が出るとカーソルは「納める/確定」（先頭・primary）に乗る――「やめる」には乗らない
- **設定**：`theme.fx` に sparkMs/shakeMs/floatMs/cardMs/revealMs（＋各 Short 版）を追加。「演出を短く」・`prefers-reduced-motion`（全アニメ静止）を尊重。効果音は設定のオン/オフ・音量に従う
- **判断ログ**：レールの針は `requestAnimationFrame` で描く（`performance.now()` は表示用のみ。判定の `at` も同じ起点から取り、core の `Math.abs(at-beat)<=halfWidth` と画面の窓を一致させた）。最初のカーソル問題は「遊んでいる間コマンド列にカーソルを出さない」で解いた（`CommandMenu` 既存の `auto` props を利用）
- **e2e**：`minigame.spec.ts` 新設――鍛冶は判定窓を広げたセーブで `data-armed` を待ち Space ×5 全命中、採掘は core と同じ器で盤面を先読みし矢印＋Enterとクリックで鉱石を掘る。音は `trace.fx.v1={sound:false}` でオフ。既存の e2e 3件の腐敗（F-06 導入窓・F-02 A窓の未対応）もついでに直した

### 共通
- 背景：オーナーが実際に遊んだ感想は **「刺激があんまりない」**。このタスクの目的は、それを直すこと。仕様の細部より「遊んで気持ちいいか」を優先してよい（変えた点は判断ログに書く）
- `docs/design/` の見た目のルールを守る。演出の数値（時間・大きさ・音量など）は theme.ts か balance.json に置き、オーナーが調整できるようにする
- バランスCIゲート（`pnpm sim:*`）が落ちる場合は、閾値ではなく数値で合わせる。仕様の意図とぶつかる場合は判断ログに「要確認」
- PRに、変更前と変更後のスクリーンショット（動きがあるものは数枚の連続画像）を添付する
