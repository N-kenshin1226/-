## タスク: [F-03] ミニゲームに動きと手応えを

### 問題（実測）
- 鍛冶は「槌の拍に合わせて Enter。5打」と出るが、**拍が画面に表示されない**（静止した●が5つと「打つ」ボタンだけ）。何に合わせればいいか分からない
- 表示どおり Space を押しても反応しなかった（0 命中のまま）
- 最初にカーソルが「やめる」に乗っている（誤って中断しやすい）

### やること
1. **タイミング系（鍛冶・演奏・釣り）**：動く拍を描く（縮む輪、左右に振れる針など）。判定窓をゲージ上に見せる。命中で火花・音・画面の小さな揺れ、外れで鈍い音。連続命中のコンボ表示
2. **盤面系（採掘・鑑定）**：マスを開ける手応え（ひびが入る、鉱石が光る）。危ないマスを開けたときの演出
3. **駆け引き系（交渉）**：相手の表情（シルエットの変化でよい）と、押している・押されているのゲージ
4. Space・Enter・クリックのどれでも操作できる。最初のカーソルは「始める」側に置く
5. 結果画面：品質の数字をカウントアップ、ティア更新・会心は F-02 の演出で
6. 判定窓・速さ・揺れの大きさなどは balance.json / theme.ts に置く（オーナーが手触りを調整する）

### 受け入れ基準
- [ ] 3種類のエンジンすべてで、何に合わせて・何を狙って操作するかが画面を見て分かる
- [ ] キーボード（Space/Enter）とクリックの両方で操作でき、e2e で命中を確認できる
- [ ] 最初のカーソルが「やめる」に乗っていない

### 共通
- 背景：オーナーが実際に遊んだ感想は **「刺激があんまりない」**。このタスクの目的は、それを直すこと。仕様の細部より「遊んで気持ちいいか」を優先してよい（変えた点は判断ログに書く）
- `docs/design/` の見た目のルールを守る。演出の数値（時間・大きさ・音量など）は theme.ts か balance.json に置き、オーナーが調整できるようにする
- バランスCIゲート（`pnpm sim:*`）が落ちる場合は、閾値ではなく数値で合わせる。仕様の意図とぶつかる場合は判断ログに「要確認」
- PRに、変更前と変更後のスクリーンショット（動きがあるものは数枚の連続画像）を添付する
