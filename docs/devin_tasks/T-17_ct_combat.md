## タスク: [T-17] CT戦闘コア

### 目的
「予兆を読む」戦闘。敵の大技を観察で読み、間合いを選ぶ。負けても年代記に残る。

### 読むもの
`docs/03_world_systems.md` §4、`docs/02_growth_system.md`（戦闘でも gain が入る設計）

### 作るもの（`packages/core/src/combat/`）
- tick ベースの戦闘状態機械。行動ごとに CT（敏捷・武器重さで変化）
- 敵は大技の前に予兆を出す。表示は固定3行。観察で内容が精密になる（曖昧→技名と残りtick）
- 敵の行動は固定ルールのパターン（content に JSON。例: 狼＝通常咬→3ターン目に飛びかかり）
- プレイ行動：攻撃（部位指定なしでOK・M1最小）／防御（予兆読みに対応）／観察／逃げる
- 勝敗と被弾をイベントとして GameState に反映（戦闘も行動として gain が入る。kind "combat"）
- 死亡時は教会蘇生：未定着経験50%と所持金（あれば）の一部を失う。数値は下がらない
- CLI から遊べる（周辺エリアで狼と戦う導線）

### 受け入れ基準
- [ ] 同じシードと行動列で同じ戦闘結果になるテスト
- [ ] 観察が低いと曖昧な予兆、高いと技名＋残りtickが出るテスト
- [ ] 死亡→蘇生で未定着経験が半減するテスト
- [ ] `pnpm check` 緑
