## タスク: [F-02] 演出（称号・自己ベスト・ランクアップを気持ちよく）

### 問題（実測）
- 称号《初仕事》《狼退治》の獲得、自己ベストの更新、報酬の受け取りが、画面下の「記録」欄に1行流れるだけ。気づかない
- 音もアニメーションもない

### やること
1. **通知ランクごとの演出**（`docs/03_world_systems.md` §6 と `docs/design/` の通知の決まり）
   - B：画面右上に札がすべり込み、数秒で消える
   - A：画面中央の窓（加護の層）。光の枠、短い効果音
   - S：画面を暗くして中央の帯（デザイン見本の「世界初の通知」）。1回の遊びで1回まで
2. **数字の動き**：起床ログの数値をカウントアップで見せる（例：25.1 → 26.8 を1秒で）。ゲージが伸びる動き。ランクアップは紋章が変わる演出
3. **効果音**：演出に合わせて鳴らす。音の仕組みそのもの（BGM・環境音・設定）は S-01 で作るので、S-01 が先に入っていればそれを使い、なければ最小限の Web Audio で鳴らして S-01 で置き換える
4. 報酬の受け取り（お金・作品）にも小さな演出
5. 演出はすべて Enter / クリックで飛ばせる。設定で「演出を短く」を選べる

### 受け入れ基準
- [ ] 称号・自己ベスト・ランクアップ・報酬が、記録欄ではなく画面上の演出で分かる
- [ ] 効果音が鳴る（設定でオフにできる）。e2e では音をオフにして動く
- [ ] すべての演出を飛ばせる

### 共通
- 背景：オーナーが実際に遊んだ感想は **「刺激があんまりない」**。このタスクの目的は、それを直すこと。仕様の細部より「遊んで気持ちいいか」を優先してよい（変えた点は判断ログに書く）
- `docs/design/` の見た目のルールを守る。演出の数値（時間・大きさ・音量など）は theme.ts か balance.json に置き、オーナーが調整できるようにする
- バランスCIゲート（`pnpm sim:*`）が落ちる場合は、閾値ではなく数値で合わせる。仕様の意図とぶつかる場合は判断ログに「要確認」
- PRに、変更前と変更後のスクリーンショット（動きがあるものは数枚の連続画像）を添付する
