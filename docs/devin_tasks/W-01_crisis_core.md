## タスク: [W-01] 世界の危機の型と進行

### やること
- `packages/content/crises/schema.ts`：危機の型のzodスキーマ（id、名前、重さの出現率、段階4つ、各段階の影響、鍵の候補、各鍵の道、真エンド・滅びの語りの参照）
- `packages/content/crises/sample.json`：テスト用の公開サンプル1つ
- 世界の作成時に、シードから危機を1つ抽選し、変数（鍵の組み合わせ、鍵を握るNPC、場所、数値）を決める。`hidden/crises/*.json` があればそれを、なければ sample を使う
- 季節の変わり目に進行値を足し、段階を進める。偉業で押し戻す（どの行動がどれだけ押し戻すかは型で定義）
- 段階ごとの**影響**をゲーム状態に反映する：エリアの閉鎖・開放、物価の倍率、敵の強さ、NPCの離散・死亡、危機の中でだけ出る依頼・素材
- 重さ「重い」は臨界で滅びの結末へ、「通常」は停滞（臨界の影響が続くだけ）
- セーブのバージョンを上げ、移行関数を書く（既存のセーブは「危機なし」→ 次の季節に危機を抽選）

### 受け入れ基準
- [ ] 同じシードで同じ危機・変数になる。シードを変えると変わる（1000シードで鍵の組み合わせが偏らない）
- [ ] 段階の進行・押し戻し・影響の適用・解除のテスト
- [ ] 重さ「重い」の出現率が balance.json の値（初期値 0.15）の範囲に収まる

### 共通
- 仕様は **`docs/08_world_crisis.md`** が正。`AGENTS.md` の絶対ルールと完了の定義を守る
- 数値は `balance.json`、データは zod スキーマ付きの JSON
- テストは公開サンプル（`packages/content/crises/sample.json`）で書く。**`packages/content/hidden/` の中身を読んだり、PRの説明・コミットメッセージ・報告に書いたりしない**（読み込む仕組みだけ作る）
- PRの説明に「判断ログ」節
