## タスク: [G-05] 情景の部品と組み合わせ

### やること（仕様 §8）
1. 背景を「情景の部品」（空・遠景・中景・前景・灯り）の組み合わせで描く仕組み（SVG）
2. 町の型・地域の型・ダンジョンの型ごとに配色と部品のセット。シードで配置を変える
3. 時間帯・天候・危機の影響を重ねる
4. 部品の追加だけで新しい情景を作れるようにする

### 受け入れ基準
- [ ] すべての型の町・地域・ダンジョンに、型らしい背景が出る（スクリーンショットの一覧をPRに）

### 共通
- 仕様は **`docs/10_world_generation.md`** が正。背景はオーナーの感想「出来る行動というかステージが少ない」
- 既存の場所（places.json）・地域・敵・発見・危機・物語のアトムを壊さない。既存の「アルディ」「ベルン」は町の型の1例として作り直してよい
- 型と生成の数値はデータ（JSON＋zod）と balance.json。名所の中身は `packages/content/hidden/`（PR・報告に書かない）
- 乱数はシード付き。同じシードなら同じ世界
- セーブのバージョンを上げ、移行関数を書く（既存のセーブは、今の地図を持つ世界として扱う）
- `docs/design/` の見た目のルールを守る。バランスCIゲートは閾値ではなく数値で合わせる
- PRの説明に「判断ログ」節、画面の変更はスクリーンショット
