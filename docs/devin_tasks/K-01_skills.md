## タスク: [K-01] 技能の種類を増やす

### 背景
オーナーの感想：**「技能の種類ももっと欲しい」**。今は13種（剣術・回避・観察・鍛冶・採掘・弁舌・演奏・釣り・鑑定と、派生の居合・受け流し・鉱脈勘・妙技）しかない。生き方の幅（`docs/01_concept.md` P4）を支えるには足りない。

### 追加する技能（既存を含めて約45種。名前は仮。調整してよい）

| 分野 | 技能 |
|---|---|
| 武技 | 剣術・短剣・槍術・斧術・弓術・投擲・格闘・盾術・回避 |
| 身のこなし | 隠密・軽業（登攀・跳躍）・騎乗・水泳・健脚（長い道のり） |
| 職人 | 鍛冶・木工・革細工・裁縫・細工（宝飾）・調合（薬）・料理・醸造 |
| 採集 | 採掘・伐採・採取（薬草・木の実）・狩猟（追跡・解体）・釣り・農耕 |
| 知 | 観察・鑑定・読み書き・算術・医術・地理・動物知識・古文書 |
| 人 | 弁舌・値切り・演奏・歌唱・統率・教授（人に教える）・賭博・礼儀作法・威圧 |
| 祈り | 祈祷（教会・加護に関わる） |
| 魔法 | 魔力操作・火魔法・水魔法・風魔法・土魔法・光魔法・闇魔法・無属性魔法・生活魔法・治癒（**中身は M-01**。このタスクでは技能の枠だけ用意してよい） |

**派生スキル**（`docs/02_growth_system.md` §9。条件は非公開、ヒントは噂・書物で）も既存の4種に加えて増やす。例：
- 鍛冶＋剣術 → 武器目利き
- 料理＋採取 → 薬膳
- 隠密＋投擲 → 暗器
- 演奏＋弁舌 → 語り部
- 鑑定＋算術 → 目利き商い
- 騎乗＋槍術 → 騎槍
- 医術＋調合 → 施療
- 地理＋健脚 → 旅慣れ

### やること
1. `packages/content/skills.json` に追加する。分野（category）を持たせる
2. **死んだ技能を作らない**：どの技能にも
   - 伸ばす行動が1つ以上（P-02 の行動・既存の仕事・戦闘・ミニゲーム・出来事に割り当てる）
   - 効いてくる場面が1つ以上（成功率・品質・選択肢の解放・会話・価格・戦闘など）
3. 武技の追加は、戦闘（F-04）で武器ごとの違いが出るようにする（間合い・速さ・予兆への対応の得意不得意）。武器を持ち替えられるようにする
4. ステータス画面：分野ごとのタブ（または見出し）で並べる。未発見の技能は `？？？` のまま
5. 技能が増えても管理が重くならないようにする：錆（`docs/02_growth_system.md` §7）と脳の容量の閾値を見直し、使っていない技能が多すぎて罰に感じないようにする
6. 出自（origins.json）ごとの初期値を、新しい技能にも振る（F-01 と合わせる）
7. 見聞録・書物・師匠に、新しい技能のヒントや学びの道を足す

### 受け入れ基準
- [ ] すべての技能に「伸ばす行動」と「効く場面」があることを検査するテスト（どちらかが欠けた技能があれば失敗）
- [ ] sim で、すべての技能がいずれかのボットで伸びる
- [ ] ステータス画面が分野ごとに整理され、45種でも見やすい（スクリーンショットをPRに）
