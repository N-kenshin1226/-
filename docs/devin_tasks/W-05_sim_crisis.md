## タスク: [W-05] 危機のバランスCIゲート

### やること
- `pnpm sim:crisis`：`docs/08_world_crisis.md` §8 の6指標を判定し、割ったら非ゼロで終了。`pnpm check` から呼ぶ
- ボット：何もしない型、生き方別（鍛冶・商い・戦い・人脈・学び）、混ざった生き方（例：鍛冶＋剣）、主流でない生き方（例：釣り＋演奏）、頂点ルートに一切向かわない型、危機に集中する型、片手間型
- 閾値は `packages/sim/thresholds.json`。**閾値を緩めて合格させない**（balance.json や危機の型の数値で合わせる）
- hidden の危機の型があるときはそれも対象にする（合否と数値だけ出し、中身は出力しない）

### 受け入れ基準
- [ ] 意図的に壊したデータでCIが落ちることを確認した
- [ ] 公開サンプルで全指標が合格

### 共通
- 仕様は **`docs/08_world_crisis.md`** が正。`AGENTS.md` の絶対ルールと完了の定義を守る
- **世界を主人公に背負わせない**（仕様 §1）。危機を主人公向けのクエストや「やるべきこと」の一覧として見せない。接点は断っても不利益なし
- 数値は `balance.json`、データは zod スキーマ付きの JSON
- テストは公開サンプル（`packages/content/crises/sample.json`）で書く。**`packages/content/hidden/` の中身を読んだり、PRの説明・コミットメッセージ・報告に書いたりしない**（読み込む仕組みだけ作る）
- PRの説明に「判断ログ」節
