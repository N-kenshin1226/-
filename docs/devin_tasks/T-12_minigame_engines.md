## タスク: [T-12] ミニゲーム基盤と3エンジン

### 目的
すべてのミニゲームを載せる `MiniGame<Input,Result>` の型と、入力型3種（タイミング／盤面推理／駆け引き）のエンジンを core に作る。リプレイ・シード固定・簡易判定の土台。

### 読むもの
`docs/03_world_systems.md` §2（共通の型）、`docs/04_tech_and_devin.md` §2

### 作るもの（`packages/core/src/minigame/`）
- `interface MiniGame<Input, Result>`：`init(ctx)` / `tick(state, input)` / `result(state)` / `autoplay(ctx)`（状態はシリアライズ可能なプレーン値）
- タイミングエンジン：時間ベースの数値窓（±ms 相当の値）。入力は「押した時刻」。判定窓・往復回数などは balance.json
- 盤面エンジン：マスを開ける系。開いたマス・ヒントを状態に持つ
- 駆け引きエンジン：手札・選択肢から1枚を選ぶ系。手札上限・相手の予告を状態に持つ
- いずれも「スキルは勝率でなく操作を助ける」設計（窓・ヒント・手札の広がり）。補助量は `f(skill)` の純関数で
- `autoplay`：スキル値から入力列を生成し、ヘッドレスで結果まで通ること

### 受け入れ基準
- [ ] 3エンジンそれぞれ、同じシードと入力列で同じ Result に収束するテスト
- [ ] 「完璧な入力なら満点、無入力なら失敗」を自動検証
- [ ] autoplay の結果が「品質=直近中央値×0.8・経験=0.5倍」の簡易判定係数に載せられる構造
- [ ] `pnpm check` 緑
