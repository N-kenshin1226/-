## タスク: [X-15] e2e整備 —— 発見・歳月・天候の見え方をブラウザで検証する

### やること
X-11（隠し発見）・X-12（NPCの歳月）・X-13（天候）は単体テストと sim で検証済みだが、
Playwright e2e がない。**ブラウザで「見える形」を固定する**のが目的（機能追加ではない）。

### 候補（実現可能なものを選ぶ。全部でなくてよい）
- **天候の行**：起床画面に「――今日の空は{weather}。」の行が出る（`wakePack`/`daily.tsx`。
  天候は seed+day から決定的 —— 固定シードの1日目の天候を調べて断言するか、行の存在だけを見る）
- **新聞の風景行**：起床画面の新聞に天候の行が載る
- **発見ヒント**：未発見の発見がある世界で、日替わりの新聞/噂に発見ヒントが回る
  （`discoveries` の hints は「必ず噂ヒント」保証 —— それが新聞に出る形を確認）
- **歳月の記事**：何らかの方法（直接 state を組み立てる、または長日数スキップの導線があれば）で
  NPC の歳月イベント後、新聞/噂/記録に人生の印が映ること
- 難度選択式（CLI のみの機能なので e2e 対象外）

### 実装
- `apps/web/e2e/` に spec を追加。既存 spec（`keyboard.spec.ts`・`screens.spec.ts`・`occasion.spec.ts` 等）の
  新規開始フロー・待機パターン（フェード完了待ち）を踏襲する
- 状態の組み立てが必要なら、既存 e2e がやっている方法（localStorage へのシード注入・UI操作）を調べて
  最も脆くない形を選ぶ。**天候は決定的なので特定日の値は seed から予測できる**
- UI の変更は原則なし（見え方の検証が目的）。ただし検証上どうしても testid が必要なら最小追加は可
