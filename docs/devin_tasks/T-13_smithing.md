## タスク: [T-13] 鍛冶ミニゲーム（タイミングの皮）＋簡易判定

### 目的
最初の「勝負所」ミニゲーム。槌のタイミング勝負で作品を作る。

### 読むもの
`docs/03_world_systems.md` §2（使い所・スキルの効き方・簡易判定）、§3

### 作るもの
- `packages/core/src/minigame/smithing.ts`：タイミングエンジンの皮。打つ→温度が上下する、の単純モデル。良温度帯で打つと品質が上がる
- スキルの効き：「良」の判定窓がスキルで広がる（`balance.json` に窓の式の係数）。Lv20/40の解放要素（最適温度帯の可視化・順番候補）は M2 回しでもよいが、データ上の枠は用意する
- 注文（order）：硬さ・納期などの条件を JSON で。内容は `packages/content/orders.json`＋zod
- 簡易判定：`autoplay` で品質=直近5回中央値×0.8、経験×0.5。称号・会心は手動時のみフラグが立つ
- CLI から遊べる：`play:cli` のメニューに「鍛冶仕事」を足す（簡易判定を選ぶと即解決、手動はキー入力のタイミング測定）

### 受け入れ基準
- [ ] シード固定で result が決定的。完璧入力=高品質、無入力=失敗
- [ ] 簡易判定の係数が spec どおり（品質0.8・経験0.5）
- [ ] 作品が Work 型（T-16 と共用の型を先に仮置きでもよい）に乗る
- [ ] `pnpm check` 緑（sim ゲートに悪化があれば閾値ではなくバランス側を見る）
