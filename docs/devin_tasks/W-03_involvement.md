## タスク: [W-03] 関与の段階と英雄への道

### やること（仕様 §6）
- 主人公の**関与**を計算する（危機に関わる行動の積み重ね＋名声・立場・関連スキル・頂点ルート）
- 段階1〜4（見届けた／支えた／担った／率いた）。閾値は balance.json
- 段階3：決着の場面への参加の打診。受けると、その場面が勝負所（戦闘・ミニゲーム・交渉）として遊べ、結果が成否に大きく効く
- 段階4（英雄）：決着の場面を**自分で起こせる**（時期を早める、やり方を選ぶ）。成否は主に主人公側の備えで決まる
- 世界は主人公を待たない：決着の時期に段階が足りなければ、NPCが挑む
- ライバルも関与を持ち、英雄になりうる（rivals.json を拡張）

### 受け入れ基準
- [ ] 段階の上がり方と、打診・自分で起こすの解放のテスト
- [ ] 段階4は、危機に集中したボットでないと届かない（W-05で検証）

### 共通
- 仕様は **`docs/08_world_crisis.md`** が正。`AGENTS.md` の絶対ルールと完了の定義を守る
- **世界を主人公に背負わせない**（仕様 §1）。危機を主人公向けのクエストや「やるべきこと」の一覧として見せない。接点は断っても不利益なし
- 数値は `balance.json`、データは zod スキーマ付きの JSON
- テストは公開サンプル（`packages/content/crises/sample.json`）で書く。**`packages/content/hidden/` の中身を読んだり、PRの説明・コミットメッセージ・報告に書いたりしない**（読み込む仕組みだけ作る）
