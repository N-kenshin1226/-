## タスク: [S-01] 音（BGM・環境音・効果音）

### 問題
- 音が一切ない

### やること
1. **音の仕組み**：BGM・環境音・効果音の3系統。それぞれ音量設定・ミュート。場面の切り替えでクロスフェード
2. **BGM**：場所と時間帯で切り替える（街の朝・昼・夜、酒場、鍛冶場、森、旧街道、戦闘、起床、ステータス、終幕）
3. **環境音**：場所ごとの音（街のざわめき、槌の音、焚き火、森の鳥と風、雨、夜の虫）。天候と時間帯で変える
4. **効果音**：決定・カーソル・戻る、槌・命中・外れ、斬撃・被弾・会心、称号・ランクアップ・世界初、お金、起床、扉・足音（移動）
5. **素材**：
   - まずは Web Audio で生成した音（効果音と簡単な環境音）で全部鳴るようにする
   - BGMは **CC0（著作権放棄）の素材**を使い、`CREDITS.md` に出典を書く。CC0以外のライセンスは使わない。見つからない場面は、Web Audio で簡単に生成した曲で代用する
   - 曲の割り当ては JSON（`packages/content/audio.json`）にして、オーナーが差し替えられるようにする
6. ブラウザの自動再生制限に対応する（最初の操作で音を有効化）
7. e2e では音をオフにして動かす

### 受け入れ基準
- [ ] すべての場所・場面でBGMか環境音が鳴り、主な操作で効果音が鳴る
- [ ] 音量・ミュートの設定が保存される
- [ ] 使った外部素材がすべて CC0 で、`CREDITS.md` に出典がある

### 共通
- 背景：オーナーが遊んだ感想 **「ランダム性がなければリアルじゃない」「音も欲しい」「行動の種類が少ない」「画面転換がない」**。このタスクはその解消が目的
- `docs/design/` の見た目のルールを守る。新しい場所の背景は、デザイン見本と同じ作り（SVGの情景レイヤー）で描く
- 乱数はすべてシード付きRNG（`rng/`）で。テストとsimは決定論的に保つ
- 数値は balance.json / theme.ts に置き、オーナーが調整できるようにする
- バランスCIゲートが落ちる場合は、閾値ではなく数値で合わせる
- PRに、変更前と変更後のスクリーンショットを添付する
