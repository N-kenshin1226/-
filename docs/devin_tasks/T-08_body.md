## タスク: [T-08] 疲労・基礎能力・オーバーワーク

### 目的
身体の成長と疲労。リアリティを「罰ではなくボーナス」として扱う。

### 読むもの
**`docs/02_growth_system.md` §5**、§2（F の項）、`docs/01_concept.md` §3（リアリティの線引き）

### 作るもの（`packages/core/src/growth/body.ts`）
- 疲労（0〜100の1本）：行動ごとに増え（行動種別ごとの値は balance.json）、睡眠で回復する（睡眠の質に比例）
- 基礎能力6種（筋力・持久・敏捷・器用・知覚・精神）：行動ごとに「負荷」が溜まり、睡眠時に定着する（スキルと同じ仕組みを再利用する）。行動種別と基礎能力の対応表は balance.json
- オーバーワーク：負荷が閾値を超えた日が3日続くと状態フラグが立つ。定着量 ×0.5、休養日（その日に行動0回で睡眠）で解除
- コマンド `{ type: "rest" }`（その日は行動しない）を追加

### 受け入れ基準
- [ ] 負荷 → 睡眠 → 基礎能力の上昇のテスト
- [ ] オーバーワークの発生と解除のテスト
- [ ] 疲労が F（gain の疲労係数）に反映される
- [ ] 毎日気にする管理項目を増やしていない（疲労以外の新しいゲージを作らない）

### 共通
- `AGENTS.md` の「絶対ルール」と「完了の定義」を守る
- ゲームの数値は `packages/content/balance.json` に置き、zodスキーマ（`balance.schema.ts`）も更新する
- 乱数を使うテストはシードを固定する
