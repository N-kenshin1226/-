## タスク: [F-01] 成長の爽快感

### 問題（実測）
- 狼との戦闘で「剣術 +3.3、回避 +4.1（未定着）」と出たのに、翌朝の起床ログは **剣術 +0.7、回避 +0.7**。原因は `balance.json` の `sleep.nightlyCapTotal: 1.7`（一晩の定着上限が全スキル合計で 1.7）。頑張った分が朝に目減りして見える
- 出自が「鍛冶屋の子」でも、全スキルが 0.0 から始まる。最初の起床ログの数字が小さく、ステータスが空っぽに見える

### やること
1. **序盤ほど大きく伸びる**ようにする。定着上限はランク（見習い・初心者…）が低いほど大きくし、上限で削られた分は「持ち越し」として起床ログに明示する（「+2.1 は明日に持ち越し」）。目安：初日に頑張れば、主なスキルが朝に +2 以上
2. **出自で初期値を持たせる**（鍛冶屋の子なら鍛冶 8〜12、など）。最初の朝から「自分の得意」が見える
3. **ランクアップを節目にする**：見習い→初心者→一人前…の到達時、起床ログで大きく扱う（後述 F-02 の演出を使う）。最初のランクアップは、普通に遊べば3日以内に起きるよう調整する
4. 行動の直後にも、得た未定着経験を数字で見せる（＋の表示が上に浮かんで消える程度）

### 受け入れ基準
- [ ] 1日目に戦闘や仕事を3回以上した場合、2日目の起床ログで主なスキルが +2 以上（sim で確認）
- [ ] 出自ごとの初期値が、最初のステータス画面に出る
- [ ] 通常の遊び方で、3日以内に最初のランクアップが起きる（sim で確認）
- [ ] 上限で削られた分が起床ログに「持ち越し」として出る

### 共通
- 背景：オーナーが実際に遊んだ感想は **「刺激があんまりない」**。このタスクの目的は、それを直すこと。仕様の細部より「遊んで気持ちいいか」を優先してよい（変えた点は判断ログに書く）
- `docs/design/` の見た目のルールを守る。演出の数値（時間・大きさ・音量など）は theme.ts か balance.json に置き、オーナーが調整できるようにする
- バランスCIゲート（`pnpm sim:*`）が落ちる場合は、閾値ではなく数値で合わせる。仕様の意図とぶつかる場合は判断ログに「要確認」
- PRに、変更前と変更後のスクリーンショット（動きがあるものは数枚の連続画像）を添付する
