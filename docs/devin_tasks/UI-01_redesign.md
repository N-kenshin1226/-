## タスク: [UI-01] デザイン見本に合わせてUIを作り直す

### 目的
オーナーが現在の仮デザインを気に入っていない。`docs/design/` のデザイン見本に合わせて、Web版のUIを「Webページ」から「ゲーム画面」に作り直す。**最優先のタスク。**

### 読むもの
1. **`docs/design/README.md`（必読。方針・色・文字・部品・決まりごと）**
2. `docs/design/screens/*.png`（完成形の見た目）と `docs/design/html/*.html`（ブラウザで開ける静的版。スタイルの値はここから取る）

### やること
1. **土台**
   - 1280×720 の固定キャンバス（`Stage`）を作り、ウィンドウに合わせて等倍で拡大縮小する（余白は黒の帯）
   - フォント3種（Cinzel、Shippori Mincho B1、Zen Kaku Gothic New）を読み込む
   - `apps/web/src/theme.ts` を見本の色・文字・枠の値で作り直す
2. **共通部品**（`apps/web/src/ui/` などにまとめる）
   - `WorldFrame`（金の窓）、`BlessingWindow`（銀青の窓）、`Paper`（紙）。角飾りを含む
   - `CommandMenu`：↑↓・Enter・Esc とマウスで操作。三角カーソル、選択中の帯、使えない状態
   - `Gauge`（区切り／細いバー＋未定着分）、`Candles`（残り行動）、`WindChip`（追い風・逆風）
   - `DialogueBox`（名札つき）、`KeyHints`（画面下の操作ガイド）、`RankCrest`（ランクの紋章）
   - `SceneBackground`：場所ごとの背景。まずは見本の SVG（夜明けの街、朝の部屋、夜の鐘楼、机）をそのまま使う
3. **画面**（見本がある画面は見本どおりに）
   - 街（拠点）、起床ログ、ステータス、世界初の通知、新聞
   - 見本のない画面（狩り・戦闘、仕事・ミニゲーム、書店、師匠、見聞録、記録、引退・転生、タイトル、開始時の選択など）は、**同じ部品と決まりごとで作る**。どの窓を使うかは README の表に従う
4. 既存の画面の機能は落とさない（コマンドの並び替えや、メニューの奥への移動はしてよい。引退・記録の削除は確認を挟む）

### 範囲
- 変更してよい：`apps/web/**`
- 変更しない：`packages/core/**` のゲームルール（UIのためにcoreのAPIが足りなければ、最小限の読み取り用の関数を追加してよい）、`docs/design/**`

### 受け入れ基準
- [ ] 見本のある5画面が、`docs/design/screens/` の画像と並べて見て同じ構成・色・書体になっている。PRに **見本と実装の画像を並べて** 添付する（Playwright のスクリーンショット）
- [ ] 1280×720 以外のウィンドウサイズ（例：1920×1080、1366×768）でも、比率を保って拡大縮小される
- [ ] マウスを使わずにキーボードだけで、起動 → 行動 → 宿で眠る → 起床ログ → ステータス → 戻る、が操作できる（e2eテスト）
- [ ] 色・枠などの値がコンポーネントに直書きされていない（theme.ts を参照）
- [ ] `pnpm check` が通る
