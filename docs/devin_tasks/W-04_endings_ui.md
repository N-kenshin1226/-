## タスク: [W-04] 危機と真エンドの画面

### やること（`docs/design/` のデザイン見本に従う）
- 街の画面：危機の段階を常に見える形で出す（HUDの札など）。公示された鍵の一覧（依頼のように見える「求む」の掲示）
- 段階が進んだときの演出（世界の層の窓で、変化した点を短く列挙）
- 鍵の詳細：道ごとの必要条件と、今の自分にできるか
- **真エンド**：ランクSの通知 → 結末画面（紙の層の語り＋その世界の年代記の一頁。関わった人々の名前が出る）。解決後もその世界で遊び続けられる
- **滅びの結末**：同じ形式で別の語り。その後は継承か転生を選ぶ
- 語りの文はテンプレートで、危機の型の結末テキスト（hidden）と、関わり方・関わった人物で組み立てる
- CLIにも最小限の表示
