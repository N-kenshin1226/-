## タスク: [W-04] 危機の見せ方と終幕の画面

### やること（`docs/design/` のデザイン見本に従う。仕様 §3・§7）
- **危機の段階を画面に常時出さない。** 新聞の記事、噂、景色（背景の差分）、物価、NPCの不在で伝える
- 接点は、通常の注文・依頼・会話の中に自然に出す（専用の「危機クエスト一覧」は作らない）
- 段階3・4の打診は、会話の窓で人物から持ちかけられる形にする
- **終幕（真エンド）**：ランクSの通知 → 結末画面（紙の層の語り＋その世界の年代記の一頁）。関与の段階に応じて主人公の痕跡を語りに織り込む。その後も遊び続けられる
- **滅び**：同じ形式で別の語り
- 人生のうちに決着しなかった場合の後日談（転生時の年代記）
- 語りはテンプレート（危機の型の語り＋関与の段階＋関わった人物・作品）で組み立てる
- CLIにも最小限の表示

### 受け入れ基準
- [ ] e2e：公開サンプルで、何もしない場合と段階3で参加した場合の両方が終幕まで通る
- [ ] 見本と並べたスクリーンショットをPRに添付

### 共通
- 仕様は **`docs/08_world_crisis.md`** が正。`AGENTS.md` の絶対ルールと完了の定義を守る
- **世界を主人公に背負わせない**（仕様 §1）。危機を主人公向けのクエストや「やるべきこと」の一覧として見せない。接点は断っても不利益なし
- 数値は `balance.json`、データは zod スキーマ付きの JSON
- テストは公開サンプル（`packages/content/crises/sample.json`）で書く。**`packages/content/hidden/` の中身を読んだり、PRの説明・コミットメッセージ・報告に書いたりしない**（読み込む仕組みだけ作る）
- PRの説明に「判断ログ」節
