## タスク: [K-03] 進化・合成・ユニークスキル

### やること（仕様 §7）
1. 進化：Lv10 に達したとき、**使い方の記録と最も合う分岐**へ自動で進化する（プレイヤーが選ぶのではない。`docs/09_skills_and_magic.md` §7.1）。分岐ごとに状況タグの重みをデータで持つ。進化のメッセージで理由を語る（「群れへ放ち続けた」など）
   - ステータスの「技」タブに、今の**傾き**を名前を伏せて示す
   - 極端な使い方は、まれに隠し分岐（hidden）へ
   - すべての技・魔法に、進化先を2〜4分岐用意する
2. 合成：技能・技の組み合わせで新しい技（約30）。条件は hidden、ヒントは噂・書物・見聞録
3. ユニークスキル（約10、hidden）：その世界で一人だけ。厳しい条件。ライバルも狙い、先に取られることがある。取った人は年代記・新聞へ（世界初の仕組み）。通知はランクS
4. ステータスの「技」タブ：進化の先を `？？？` で見せる

### 受け入れ基準
- [ ] 同じ技でも、使い方の記録が違えば別の分岐に進化するテスト
- [ ] 進化・合成・ユニークの獲得と、ユニークの一人だけ制約のテスト（公開サンプルのデータで）
- [ ] ライバルがユニークを先に取る場合の新聞・年代記の記録

### 共通
- 仕様は **`docs/09_skills_and_magic.md`** が正。背景はオーナーの要望「魔法も入れて」「戦闘スキルが多いと面白い」「なろう系やMMOのような多彩さ」
- 技・魔法・合成・ユニークはすべてデータ（JSON＋zod）。合成とユニークの条件は `packages/content/hidden/` に置き、**PRの説明・コミットメッセージ・報告に中身を書かない**
- `docs/design/` の見た目のルールを守る。数値は balance.json に
- バランスCIゲートが落ちる場合は、閾値ではなく数値で合わせる
- PRの説明に「判断ログ」節、画面の変更はスクリーンショット
