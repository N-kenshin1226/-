## タスク: [K-03] 進化・合成・ユニークスキル

### やること（仕様 §7）
1. 進化：Lv10＋条件で上位へ（分岐は選択）。演出つきのシステムメッセージ
2. 合成：技能・技の組み合わせで新しい技（約30）。条件は hidden、ヒントは噂・書物・見聞録
3. ユニークスキル（約10、hidden）：その世界で一人だけ。厳しい条件。ライバルも狙い、先に取られることがある。取った人は年代記・新聞へ（世界初の仕組み）。通知はランクS
4. ステータスの「技」タブ：進化の先を `？？？` で見せる

### 受け入れ基準
- [ ] 進化・合成・ユニークの獲得と、ユニークの一人だけ制約のテスト（公開サンプルのデータで）
- [ ] ライバルがユニークを先に取る場合の新聞・年代記の記録

### 共通
- 仕様は **`docs/09_skills_and_magic.md`** が正。背景はオーナーの要望「魔法も入れて」「戦闘スキルが多いと面白い」「なろう系やMMOのような多彩さ」

- バランスCIゲートが落ちる場合は、閾値ではなく数値で合わせる
