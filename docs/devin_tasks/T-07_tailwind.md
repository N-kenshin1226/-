## タスク: [T-07] 今日の追い風

### 目的
毎日の最適行動を変え、固定ルーチンへの収束を防ぐ。

### 読むもの
**`docs/02_growth_system.md` §4**、§2（W の項）

### 作るもの（`packages/core/src/growth/tailwind.ts`）
- `rollTailwind(state, rng) → Tailwind[]`：睡眠時に翌日の追い風・逆風を1〜2種抽選する
- 種類の定義は `packages/content/tailwinds.json`（id、対象スキルまたは行動種別、倍率：追い風1.3／逆風0.8）＋ zodスキーマ。初期データ8種
- **直近の行動の偏り**（直近3日の行動種別ごとの回数）を見て、偏っている分野ほど逆風が出やすくなるよう重みを付ける（重みの式の係数は balance.json）
- T-05 の `W` を実装に置き換える
- 起床ログ（T-06）に追い風を含める

### 受け入れ基準
- [ ] 同じシードと状態から同じ追い風が出る
- [ ] 1つの分野だけを続けた状態では、その分野の逆風の出現率が有意に上がる（1万回の抽選で検証）
- [ ] W が gain に反映される

### 共通
- `AGENTS.md` の「絶対ルール」と「完了の定義」を守る
- ゲームの数値は `packages/content/balance.json` に置き、zodスキーマ（`balance.schema.ts`）も更新する
- 乱数を使うテストはシードを固定する
- PRの説明に「判断ログ」節を設け、仕様にない判断を1行ずつ書く
