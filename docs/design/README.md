## 方針
**「Webページ」ではなく「ゲーム画面」を作る。**

1. **固定キャンバス**：基準解像度 1280×720（16:9）。画面全体をこのキャンバスとして作り、ウィンドウサイズに合わせて `transform: scale()` で等倍拡大縮小する（余白は黒の帯）。スクロールするページにしない
2. **背景に情景**：どの画面も、場所の情景（今は図形で描いた仮の絵）を一番下のレイヤーに置き、窓をその上に重ねる。背景は場所ごとに差し替え可能な独立したコンポーネントにする
3. **3種類の窓**
   | 窓 | 使う場所 | 作り |
   |---|---|---|
   | **世界の窓（金）** | コマンド、会話、HUD | 暗い地＋金の三重線（`inset` の box-shadow を重ねる）＋菱形の角飾り（SVG） |
   | **加護の窓（銀青）** | ステータス、起床ログ、システムの声 | 濃紺の地＋銀青の三重線＋円の角飾り＋外光 |
   | **紙** | 新聞、手紙、書物、見聞録 | 生成りの紙＋焼けた縁（inset shadow）＋わずかな傾き＋落ち影 |
4. **キーボードだけで全部遊べる**：コマンドは ↑↓ で選び、Enter で決定、Esc で戻る。マウスでも操作できる。選択中の行は左の三角カーソルと金の帯
5. **画面下に常に操作ガイド**（`Enter 決定` などのキー表示）

| 書体 | 用途 |

## 部品
- **コマンド**：高さ44px以上。状態は「選択中（三角カーソル＋金の帯）」「通常」「使えない（灰色）」の3つ
- **ゲージ**：疲労は10マスの区切りゲージ。熟練度は細いバー＋未定着分を半透明で重ねる
- **残り行動**：蝋燭のアイコン（灯っている＝残り）
- **追い風・逆風**：右上の札（▲金／▼珊瑚色）
- **会話窓**：上辺に名札（金のプレート）、右下に ▼
- **ランクの紋章**：盾形にランクの頭文字（見・初・一・熟・達・極）
- **通知**：S＝画面を暗くして中央の帯（1回の遊びで1回まで）／A＝窓の中の光る枠／B＝ログに1行

## 決まりごと
1. 画面は 1280×720 の固定キャンバス。スクロールするWebページにしない
2. 背景には必ず場所の情景を描く。窓はその上に重ねる
3. システムの声は銀青の窓、人の言葉は金の窓か紙
4. キーボードだけで全部遊べる。画面下に常に操作ガイドを出す
5. 数値は Cinzel、伸びは金の「+」、逆風は珊瑚色の「▼」。色だけで区別しない
6. 主役のボタン（宿で眠る、起きる、など）は1画面に1つ
7. 引退・記録の削除など戻せない操作は、メニューの奥に置き、確認を挟む
8. 色・余白・枠の値はテーマ定義（`apps/web/src/theme.ts`）に集め、コンポーネントに直接書かない
