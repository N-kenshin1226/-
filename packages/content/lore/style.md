# 文体ガイド（アトムの本文）

- 書き手の感情を入れない。見えたもの・残ったものを淡々と書く
- 長さは 10〜120 字（canon.json の styleLint が機械的に検査する）
- 禁止語・禁止表現は canon.json `styleLint.forbidden` を見る（現代語・メタ語は禁止）
- `reliability: fact` の文に推量表現（らしい・そうだ・かもしれない）は使わない
- `reliability: rumor` は食い違っていてよい。断定しすぎない
- 出来事を直接描写しない。断片（物・場所・人の一言）から見せる
- 例：「柄に〈ベルナ〉と刻まれている。打面だけが妙に磨かれている。」
