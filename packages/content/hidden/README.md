# hidden/ — 隠し要素の置き場（オーナーは読まない）

ネタバレ防止のための隔離ディレクトリ（`docs/07_story.md` §5）。

- ここには、アトムの細部・隠し条件・派生スキルの条件・物語の結末を置く
- オーナーはこのディレクトリの中身を**読まない**
- **中身を PR の説明・コミットメッセージ・コメント・報告に書かないこと**
- 隠し要素も zod スキーマで検証するが、検証結果の出力には ID と件数だけを出す

## crises/ の置き方

- `crises/types.json` 1ファイルに `crises` 配列でまとめる（`crises/schema.ts` のファイル形式）。
  ブラウザは fs を使えないため、`src/crises.ts` がこの1ファイルを静的 import して同梱する。
  バラバラの `*.json` を増やすと node 側（sim）には読まれるがブラウザに同梱されないので、追加もこのファイルの配列に書く
